# 面向大语言模型的群体优化（PSO，ACO）

> 生物启发式优化正在大语言模型领域回归。**LMPSO**（arXiv:2504.09247）使用粒子群优化，其中每个粒子的速度是一个提示，大语言模型生成下一个候选解；在结构化序列输出（数学表达式、程序）上效果良好。**Model Swarms**（arXiv:2410.11163）将每个大语言模型专家视为模型权重流形上的粒子群粒子，在9个数据集上仅用200个实例就报告了**平均13.3%的提升**，超过12个基线。**SwarmPrompt**（ICAART 2025）混合了粒子群优化 + 灰狼算法用于提示优化。**AMRO-S**（arXiv:2603.12933）是受蚁群优化启发的信息素专家，用于多智能体大语言模型路由——**4.7倍加速**，可解释的路由证据，质量门控的异步更新将推理与学习解耦。本课在提示参数空间上实现粒子群优化，在智能体路由上实现蚁群优化，衡量这些经典算法为何适合大语言模型时代，以及何时不适合。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** Phase 16 · 09（并行群体网络），Phase 16 · 14（共识与拜占庭容错）
**所需时间：** 约75分钟

## 问题

你有一个提示在任务评估中得分62%。你想改进它。朴素的做法是无梯度的手动调整，这扩展性很差。强化学习需要奖励信号和足够的训练轮次。对提示进行反向传播并不可行——提示是离散字符串，而非可微参数。

经典生物启发式优化——粒子群优化用于连续搜索空间，蚁群优化用于路径选择——正是为此设计的：无梯度、基于群体、每次评估成本低廉。将它们与大语言模型搭配用于无梯度搜索步骤，你就得到了一个出奇实用的优化器。

同样的模式适用于多智能体系统中的智能体*路由*。蚁群优化风格的信息素轨迹记录哪个智能体在哪个任务类型上表现最好，让路由器利用该轨迹，并衰减信息素以便重新发现路由。

## 概念

### 粒子群优化回顾（Kennedy & Eberhart 1995）

粒子群优化：连续搜索空间中的粒子群体。每个粒子有位置`x_i`和速度`v_i`。每次迭代：

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
evaluate fitness(x_i)
update p_best_i if improved
update g_best if global best
```

其中`p_best`是粒子自身的最优解，`g_best`是群体的最优解，`w, c1, c2`是惯性 + 认知 + 社会权重，`r1, r2`是随机因子。

### 粒子群优化用于大语言模型输出 — LMPSO

arXiv:2504.09247将粒子群优化适配于大语言模型生成的结构化输出（数学表达式、程序）。每个粒子是一个候选输出。速度是一个*提示*，描述如何将当前输出向个体/全局最优方向修改。大语言模型从速度提示生成新的输出。速度的"惯性"类似于"进行小的增量变化"这样的提示。

这种方法适用于：
- 输出是结构化的（可解析、可评估）。
- 适应度是自动计算的（测试运行、算术评估）。
- 群体规模小（约10-30个粒子），使大语言模型调用总量可控。

当适应度需要人工审查时，这种方法不太适用——每次迭代的成本变得过高。

### Model Swarms

arXiv:2410.11163将粒子群优化从输出层转移到*模型*层。每个"粒子"是一个专家大语言模型（参数）。群体通过无梯度更新将参数向集体最优方向移动。报告结果：在9个数据集上超过12个基线，平均提升13.3%，每次迭代仅需200个实例。

关键洞察在于大语言模型专家模型在共享参数流形（适配器权重、LoRA增量）中已经彼此接近。在这个低维子空间上的粒子群优化既便宜又有效。

### 蚁群优化回顾（Dorigo 1992）

蚁群优化：蚂蚁遍历图；每条路径有信息素轨迹。蚂蚁的移动概率按信息素强度加权。完成任务的蚂蚁按解决方案质量比例沉积信息素。信息素随时间衰减。

### AMRO-S — 蚁群优化用于智能体路由

arXiv:2603.12933使用蚁群优化进行多智能体路由。每种任务类型是一个"目的地"；每个智能体是一条可能的路由。信息素增强了产生良好输出的路由。关键贡献：

- **可解释的路由证据。** 信息素强度是人类可读的信号。
- **质量门控的异步更新。** 信息素仅在质量检查通过后更新，将推理与学习解耦。
- **在多智能体路由基准上实现4.7倍加速。**

质量门控很重要：没有它，快速但错误的智能体会累积信息素，系统会锁定在错误的路由上。

### 何时使用粒子群优化/蚁群优化

**使用粒子群优化的场景：**
- 搜索空间是连续的或可映射到连续参数（提示嵌入、LoRA权重、数值生成参数）。
- 适应度计算廉价且自动化。
- 群体规模可以很小（10-30）。

**使用蚁群优化的场景：**
- 你有路由或路径选择问题。
- 决策会随时间强化（相同的任务类型会重复出现）。
- 你需要路由决策的可解释证据。

**两者都不适用的场景：**
- 适应度需要人工审查（每次迭代成本太高）。
- 搜索空间是离散的且组合性复杂，粒子群优化无法覆盖（改用遗传算法）。
- 实时决策需要严格的延迟（粒子群优化/蚁群优化相对于单次启发式收敛缓慢）。

### 为什么生物启发式仍然有效

基于梯度的方法需要可微信号。大语言模型输出和路由决策并非简单可微的。伪梯度方法（强化学习路由器、DPO风格的提示调优器）可行但需要昂贵的训练。

粒子群优化和蚁群优化只需要一个*评估*函数。如果你能对候选输出或路由决策打分，你就能在该空间上优化。这使得适用门槛大大降低。

### 实际限制

- **群体预算。** N个粒子 × T次迭代 × 每次评估成本。对于每次调用约0.02美元的大语言模型评估，20个粒子的粒子群优化运行50次迭代的成本约为20美元。请做好规划。
- **探索与利用。** 信息素衰减率和粒子群优化惯性之间存在权衡；衰减过快 → 遗忘解决方案；衰减过慢 → 陷入早期局部最优。
- **灾难性漂移。** 两种算法都可能收敛后发散，如果适应度景观发生变化（新的数据分布）。监控最优适应度的稳定性。

## 开始构建

`code/main.py` 实现了：

- `LMPSO` — 在数值提示参数（温度、top_k权重）上的粒子群优化。每个粒子的"大语言模型生成"被模拟为脚本化的适应度函数。运行算法30次迭代并展示g_best的收敛过程。
- `AMRO_S` — 蚁群优化风格的路由。3个智能体，4种任务类型，信息素矩阵，100个路由任务。随时间打印（任务类型 → 智能体选择）分布以展示轨迹形成。
- 对比：相同任务流上随机路由与蚁群优化路由的质量和延迟。

运行：

```
python3 code/main.py
```

预期输出：
- LMPSO：g_best适应度在30次迭代中从随机提升到接近最优。
- AMRO-S：信息素表稳定在每种任务类型的正确智能体上；蚁群优化路由在质量上比随机路由提升约30-40%，同时减少延迟（更少的重试）。

`outputs/skill-swarm-optimizer.md` 帮助在粒子群优化、蚁群优化、遗传算法和基于梯度的优化器之间为大语言模型/智能体优化问题做出选择。

## 投入生产

- **从小规模开始。** 10-20个粒子，20-50次迭代。仅在收敛曲线显示明显收益时扩大规模。
- **记录每代的信息素或g_best。** 没有轨迹的群体优化调试非常痛苦。
- **质量门控更新。** 特别是对于蚁群优化路由：快速但错误的智能体绝不能累积信息素。
- **在分布漂移时重置衰减。** 当你的评估分布改变时，陈旧的信息素已经过时；重置或临时加倍衰减率。
- **限制每次迭代的成本。** 输出每次迭代的成本指标。每次迭代花费500美元但仅提升0.5%的粒子群优化是无法上线的。

## 练习

1. 运行`code/main.py`。观察LMPSO的收敛过程。将群体规模分别设为5、10、20、50。在什么规模下收敛时间趋于饱和？
2. 实现一个"灾难性漂移"实验：在第30次迭代后改变适应度函数。粒子群优化的适应速度有多快？重置`p_best`是否有帮助？
3. 为AMRO-S添加质量门控：仅在评估分数大于0.7的运行中沉积信息素。这与无门控版本相比如何改变收敛？
4. 阅读LMPSO（arXiv:2504.09247）。将论文中"速度即提示"映射回你的数值速度。模拟中丢失了什么，保留了什么？
5. 阅读AMRO-S（arXiv:2603.12933）。实现解耦的"推理快速路径"和异步信息素更新。这在持续负载下如何改变系统延迟？

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------------|------------------------|
| PSO | "粒子群优化" | Kennedy-Eberhart 1995。基于群体的无梯度优化器。 |
| ACO | "蚁群优化" | Dorigo 1992。通过信息素轨迹进行路径/路由优化。 |
| LMPSO | "带大语言模型生成的粒子群优化" | arXiv:2504.09247。速度是提示；大语言模型生成候选解。 |
| Model Swarms | "专家权重上的粒子群优化" | arXiv:2410.11163。在模型参数子空间上的无梯度更新。 |
| AMRO-S | "用于智能体路由的蚁群优化" | arXiv:2603.12933。任务类型 × 智能体的信息素矩阵。 |
| p_best / g_best | "个体最优 / 全局最优" | 每个粒子和群体迄今发现的最优解。 |
| 信息素 | "路由记忆" | 边上的强度；随时间衰减；按质量沉积。 |
| 质量门控更新 | "只从好的运行中学习" | 信息素沉积以质量检查为条件。 |
| 灾难性漂移 | "分布漂移" | 适应度景观改变；旧的p_best和信息素变得陈旧。 |
