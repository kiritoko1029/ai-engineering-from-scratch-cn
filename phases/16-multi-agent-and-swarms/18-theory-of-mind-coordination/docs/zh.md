# 心智理论与涌现协调

> Li等人（arXiv:2310.10701）表明，合作文本游戏中的大语言模型智能体表现出**涌现的高阶心智理论**（ToM）——推理另一个智能体对第三个智能体信念的信念——但由于上下文管理和幻觉问题，在长程规划上表现不佳。Riedl（arXiv:2510.05174）在群体层面测量了高阶协同，发现**只有**心智理论提示条件才能产生与身份关联的差异化和目标导向的互补性；较低能力的大语言模型仅表现出虚假涌现。也就是说，协调涌现是有条件的且依赖模型的，并非免费获得。本课实现了一个最小化的心智理论感知智能体，在有无心智理论提示的条件下运行合作任务，并按照Riedl 2025的协议测量协调增量。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** Phase 16 · 07（心智社会与辩论），Phase 16 · 17（生成式智能体）
**所需时间：** 约75分钟

## 问题

多智能体协调常常看起来很神奇：智能体分工协作、相互预见、避免冗余。通常这种"涌现"是提示工程的产物——有人告诉智能体"要协调"。去掉提示，协调就消失了。

Riedl 2025的发现更加严格：在受控条件下，协调只有在智能体被提示去推理**其他智能体的心智**（心智理论）时才会涌现。没有心智理论提示时，即使是强大的模型也表现出无法通过统计检验的协调模式。这对生产很重要：团队发布依赖提示且脆弱的"多智能体协调"功能。

本课将心智理论视为一种具体能力（推理关于信念的信念），构建一个最小化的心智理论感知智能体，并衡量真正的协调与提示包装的协调之间的差异。

## 概念

### 心智理论的含义

发展心理学：3岁儿童认为每个人的内心世界都和自己一样。5岁儿童理解他人有不同的信念。7岁儿童能推理关于信念的信念（"她认为我认为球在杯子下面"）。这些分别是零阶、一阶和二阶心智理论。

对于大语言模型智能体，心智理论的阶数对应：

- **零阶：** 没有对他人的心智模型。智能体仅基于自身观察行动。
- **一阶：** 智能体对每个其他智能体的信念有心智模型。"Alice相信X。"
- **二阶：** 智能体对递归信念建模。"Alice相信Bob相信X。"

Li等人2023年发现，一阶和二阶心智理论在合作博弈中的大语言模型智能体中涌现，但会随着长时间跨度和不可靠通信而退化。

### Sally-Anne测试简介

1985年的错误信念测试：Sally将一颗弹珠放入篮子A，然后离开。Anne将其移到篮子B。Sally回来时会去哪里找？拥有一阶心智理论的儿童会说篮子A（Sally的信念与现实不同）。没有心智理论的儿童会说篮子B。

GPT-4时代的大语言模型在直接提问时能通过Sally-Anne风格的测试。当叙述变长、场景多次变化或问题间接表述时，它们就会失败。这就是2026年生产环境中心智理论的实际状况。

### Riedl的协调测量

Riedl（arXiv:2510.05174）构建了一个群体规模的测试：N个智能体，合作目标，可变的提示条件。测量：

1. **与身份关联的差异化。** 智能体是否随时间发展出稳定的角色区分？
2. **目标导向的互补性。** 智能体的行动是否互补（不同的子任务）而非重复？
3. **高阶协同。** 一种统计测量，衡量群体是否实现了任何子集都无法实现的成果。

结果：只有在心智理论提示条件下，三个指标才产生高于基线的信号。没有心智理论提示时，中等能力模型的指标接近随机水平。大型模型在没有显式心智理论提示时也表现出一定程度的协调，但效果小于显式提示。

### 协调幻觉

在没有统计控制的情况下，演示中的"涌现协调"通常反映：

- 提示工程中预设了协调（系统提示中写着"一起合作"）。
- 观察者偏差（我们看到了预期的模式）。
- 对成功运行的事后筛选。

宣称"涌现协调"但没有可衡量信号的生产系统应被视为营销手段。在宣称之前先进行测量。

### 最小化的心智理论感知智能体

结构：

```
agent state:
  own_beliefs:    {facts the agent believes}
  other_models:   {other_agent_id -> {beliefs_the_agent_attributes_to_them}}
  actions_last_N: [history of others' actions]

observation update:
  - update own_beliefs from direct observation
  - update other_models[agent_id] from their action + prior beliefs

action selection:
  - enumerate candidate actions
  - for each, predict what each other agent will do next given their modeled beliefs
  - pick action that maximizes joint outcome under those predictions
```

`other_models`属性就是心智理论状态。一阶心智理论仅保留一个层级。二阶心智理论添加`other_models[i][other_models_of_j]`——我认为智能体i认为智能体j相信什么。

### 为什么长程有害

Li等人记录：上下文限制导致智能体忘记哪个信念属于谁。幻觉在其他智能体模型中添加了虚假信念。两者都会产生"我以为他认为X"的错误，这些错误会随时间累积。

论文及2024-2026年后续研究中记录的缓解措施：

- **在提示中显式维护心智理论状态。** 结构化格式：`{agent_id: belief_list}`。强制检索以保留身份-信念绑定。
- **更短的推理链。** 每轮更少的心智理论更新减少累积幻觉。
- **外部心智理论存储。** 在大语言模型上下文之外维护模型；每轮仅注入相关部分。

### 心智理论在生产中的失败场景

- **对抗性环境。** 拥有良好心智理论的智能体更容易被操控（你可以对它们关于你的心智模型建模，然后加以利用）。
- **异构团队。** 当模型不同时，对一个对手有效的心智理论模型无法泛化。
- **依赖事实的任务。** 心智理论关乎信念；如果正确性取决于事实，心智理论可能是一种干扰。

### 你能实际测量的协调

三个实际信号，表明团队的协调是真实的而非提示包装的：

1. **随时间的互补性。** 在多轮任务中，智能体的行动是否覆盖了不相交的子任务？
2. **预见性。** 智能体A在T+1轮的行动是否依赖于对B在T+2轮行动的预测，且该预测被证明正确？
3. **纠正性。** 当A在T轮误读了B的信念时，A是否在T+2轮进行了纠正？

这些在已记录日志的多智能体系统中是可测量的。它们是"协调"叙事的实质版本。

## 开始构建

`code/main.py` 实现了：

- `ToMAgent` — 追踪自身信念和对每个其他智能体的信念模型。
- 一个合作任务：三个智能体必须从三个箱子中收集三个代币；每个箱子只能放一个代币。智能体无法通信；它们从彼此的行动中推断意图。
- 两种配置：`zeroth_order`（无心智理论）和`first_order`（具有一层信念模型的心智理论）。
- 200次随机试验的测量：完成率、重复率（两个智能体瞄准同一个箱子）、平均完成轮次。

运行：

```
python3 code/main.py
```

预期输出：零阶智能体的重复率约35%，在10轮内完成约60%的试验。一阶心智理论智能体的重复率约5%，完成率约95%。这一差距就是可测量的协调效应。

## 投入生产

协调声明清单：

- **对照条件。** 去掉协调提示的系统版本。两者都进行测量。
- **统计检验。** 系统与对照之间的差异在你的指标上是否在`p < 0.05`水平显著？
- **互补性测量。** 随时间的行动不相交性，而非仅仅是最终成功率。
- **失败案例日志。** 当智能体协调失误时，心智理论状态是什么样的？
- **模型能力声明。** 如果效应在较小模型上消失，如实说明。

## 练习

1. 运行`code/main.py`。确认一阶心智理论将重复率降低了约7倍。当扩展到5个智能体和5个箱子时，差距是否保持？
2. 实现二阶心智理论（智能体A建模B对C的看法）。它是否比一阶有所改善？在什么任务上？
3. 向心智理论状态注入**幻觉**：每轮随机翻转一个信念。这会将一阶性能降低多少？
4. 阅读Li等人（arXiv:2310.10701）。复现"长程退化"发现：当轮次从10增加到30时，你的一阶心智理论性能如何变化？
5. 阅读Riedl 2025（arXiv:2510.05174）。在你的模拟日志上实现高阶协同统计量。在没有心智理论提示条件的情况下，该效应是否存在？

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------------|------------------------|
| 心智理论 | "理解他人的心智" | 对另一个智能体的信念建模的能力。按阶数分级（0，1，2+）。 |
| Sally-Anne测试 | "错误信念测试" | 1985年发展心理学实验；大语言模型通过简单版本，失败于复杂版本。 |
| 一阶心智理论 | "A相信X" | 对另一个智能体关于事实的信念建模。 |
| 二阶心智理论 | "A相信B相信X" | 递归建模深一层。 |
| 与身份关联的差异化 | "稳定的角色" | Riedl的指标：角色持续存在，而非随机。 |
| 目标导向的互补性 | "不相交的行动" | 智能体瞄准不同的子任务，而非同一个。 |
| 高阶协同 | "群体超越任何子集" | Riedl衡量真实协调的统计量。 |
| 协调幻觉 | "看起来很协调" | 没有可衡量信号的提示包装协调外观。 |
