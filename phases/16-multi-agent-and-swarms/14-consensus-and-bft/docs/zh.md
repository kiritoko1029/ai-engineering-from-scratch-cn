# 智能体的共识与拜占庭容错

> 经典分布式系统 BFT 遇上随机性的 LLM。2025-2026 年出现了三个研究方向：**CP-WBFT**（arXiv:2511.10400）通过置信探测对每票加权；**DecentLLMs**（arXiv:2507.14928）采用无领导者架构，通过并行工作提案和几何中位数聚合；**WBFT**（arXiv:2505.05103）将加权投票与层次结构聚类相结合，划分核心节点和边缘节点。"Can AI Agents Agree?"（arXiv:2603.01213）的实证结果表明，即使是标量共识在今天也是脆弱的 —— 一个欺骗性智能体就能破坏 Mixture-of-Agents。BFT 是必要的，但不充分。本课构建一个最小的 BFT 协议，注入三种智能体特有的攻击（拜占庭式撒谎、谄媚式从众、相关错误单一文化），并衡量每种共识变体的应对能力。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 第 16 阶段 · 07（心智社会与辩论），第 16 阶段 · 13（共享记忆）
**所需时间：** 约 75 分钟

## 问题

你有 N 个 LLM 智能体各产生一个答案。它们不一致。多数投票选出了错误的答案，因为两个智能体是相关的（相同的基础模型、相同的训练数据、相同的失败模式）。第三个智能体恰好以一种新颖的方式出错 —— 所以多数是虚假多数。

现在加入一个欺骗性智能体：它故意撒谎。或者一个谄媚型智能体：它同意最后发言的人。在经典 BFT 中，假设拜占庭节点的比例 `f < n/3` 且行为任意。2026 年的现实是，LLM 节点即使在诚实的情况下也是随机的，跨模型存在相关性，并且受彼此输出的影响。你不能把它们当作独立的伯努利投票者。

经典 BFT（PBFT，1999）没有错 —— 它只是不完整。它处理任意比特翻转。它不处理"三个诚实的智能体因为共享训练数据而共享一个幻觉"。本课从 PBFT 的基础出发，叠加三层 2025-2026 年的适配。

## 概念

### 经典 BFT 给你什么

实用拜占庭容错（Castro 和 Liskov，OSDI 1999）容忍 `f < n/3` 个拜占庭节点。协议有三个阶段（预准备、准备、提交）和两个原语（签名消息、法定人数证书）。在 `n >= 3f + 1` 个诚实或恶意节点之间达成单值共识。

保证是强的，但假设：

1. **独立故障。** 拜占庭节点不串通。
2. **诚实节点真正诚实。** 诚实输出的正确性不是问题；协议只对齐分歧。
3. **问题有真实答案。** 对错误事实达成共识仍然是共识。

LLM 智能体违反了所有三个假设。两个运行相同基础模型的智能体共享故障。一个"诚实"的 LLM 仍然会产生幻觉。在模糊问题上，"真相"就是智能体决定的 —— 没有外部预言机。

### 三种 LLM 特有的攻击

**拜占庭式撒谎。** 一个智能体输出故意错误的答案。如果 `f < n/3`，经典 BFT 可以处理。

**谄媚式从众。** 一个智能体在投票前阅读其他人的答案，并与最后发言的人保持一致。不是恶意的，但与最大声的声音相关。经典 BFT 无法阻止，因为该智能体通过了所有签名检查。

**相关错误单一文化。** 三个智能体共享一个基础模型。它们产生相同的错误幻觉答案。多数是错的。经典 BFT 无济于事，因为三个智能体"诚实地"一致。

### 2025-2026 年的应对方案

**CP-WBFT**（arXiv:2511.10400）— 置信探测加权 BFT。每个投票者在其答案上附加一个置信探测（自报告的概率，或单独校准模型的预测）。投票权重随置信度缩放。报告在完全图上提升了 85.71% 的 BFT 效果。缓解：谄媚式从众（从众智能体在自愿立场上往往置信度较低）。

**DecentLLMs**（arXiv:2507.14928）— 无领导者。工作智能体并行提案，评估智能体对提案评分，最终答案是评分位置的几何中位数。当 `f < n/2` 时具有鲁棒性。缓解：拜占庭式撒谎和相关错误（几何中位数对异常值具有鲁棒性，趋向密集集群而非模型偏向的平均值）。

**WBFT**（arXiv:2505.05103）— 带层次结构聚类的加权 BFT。投票权重由响应质量加上从历史学习的信任分数分配。将智能体聚类为核心和边缘；核心智能体必须先达成共识，边缘智能体跟随。缓解：可扩展性（核心共识小而快）以及部分缓解单一文化（核心可以选择多样性）。

### 实证："Can AI Agents Agree?"（arXiv:2603.01213）

该论文衡量了多个前沿模型上 LLM 智能体的标量共识（对单个数值达成一致）。结果令人不安：

- 即使没有对手，LLM 智能体在许多基准上对标量问题的分歧率超过 30%。
- 一个采取欺骗人格的智能体可以将 Mixture-of-Agents 的共识拉离诚实基线 40 多个百分点。
- 分歧率与模型多样性相关 —— 异构集成比同构集成分歧更多（好：错误不相关）但也漂移更慢（坏：达成共识时间更长）。

核心观点：BFT 给你对齐输出的机制，但它不告诉你对齐的输出是否正确。结合验证（第 16 阶段 · 08 角色专业化）、多样性（第 16 阶段 · 15 辩论变体）和评估智能体（第 16 阶段 · 24 基准测试）使用。

### 核心协议，精简版

LLM 智能体的最小 BFT 轮次：

```
1. task arrives; each agent i produces answer a_i
2. each agent attaches confidence probe c_i in [0, 1]
3. aggregator collects (a_i, c_i) from all n agents
4. aggregator groups by semantic cluster (equivalent answers)
5. aggregator computes weight for each cluster C:
     w(C) = sum_{i in C} c_i
6. winner = cluster with max weight, if max > threshold * sum(c_i)
   else: retry or escalate
7. minority clusters logged with provenance for post-hoc audit
```

语义聚类步骤是 LLM 特有的转折。两个答案"该研究报告 4.2%"和"4.2% 的改进"属于同一聚类。朴素的字符串相等检查会遗漏这一点。在生产中，使用廉价的嵌入模型或显式规范化。

### 阈值调优

`threshold` 参数决定何时接受、何时重试。太低：你接受弱多数。太高：你永远不接受任何结果。经验范围：`n=5-7` 个智能体时为 0.5-0.67，`n` 更小时更高。低于阈值时，升级到人类或不同的智能体集成。

### 共识无济于事的场景

- **模糊问题。** 如果问题没有真实答案，共识就是意见。如实说明。
- **复合问题。** "编写代码并解释它" —— 两个答案。分别对每个投票。
- **对抗性多轮。** 如果智能体可以观察先前的轮次并模仿（Du 2023 辩论），它们会开始彼此同意而不管真相。限制轮次（通常 2-3 轮）。

## 开始构建

`code/main.py` 实现了：

- `AgentVoter` — 带有（答案、置信度）的脚本策略。
- `MajorityVote` — 经典多数投票。
- `CPWBFT` — 带语义聚类的置信加权投票。
- `DecentLLMs` — 对评分提案进行几何中位数聚合。
- `Scenario` — 在三种攻击模式下运行每个聚合器。

实现的攻击模式：

1. `byzantine`：一个智能体以高置信度撒谎。
2. `sycophancy`：一个智能体复制它看到的第一个答案，置信度匹配。
3. `monoculture`：三个智能体共享一个错误答案（相关错误），置信度中等。

运行：

```
python3 code/main.py
```

预期输出：一个（攻击、聚合器）-> 最终答案的表格，正确答案高亮显示。多数投票在单一文化场景中失败。CPWBFT 的置信加权缓解了谄媚。DecentLLMs 的几何中位数在单一文化不到一半时趋向诚实集群。

## 投入生产

在投入任何共识机制之前：

- **至少使用上述三种模式进行攻击测试。** 你的协议应该可预测地失败，而不是静默失败。
- **记录每个少数派集群**及其来源。少数派集群是相关错误的早期预警系统。
- **强制限制轮次。** 不要"持续辩论直到达成一致" —— 那会奖励谄媚。
- **将共识与正确性分离。** 共识输出交给验证器；验证器独立于集成。
- **监控共识率。** 急剧上升意味着从众偏差；急剧下降意味着模型漂移。

## 练习

1. 运行 `code/main.py`。确认多数投票在单一文化攻击中失败，但当单一文化置信度低于 0.7 时 CPWBFT 部分缓解了它。
2. 添加第四种攻击模式：**静默弃权** —— 一个智能体拒绝回答（"我不知道"）。每个聚合器应如何处理弃权？实现你的选择。
3. 将语义聚类从字符串规范化替换为嵌入相似度（使用任何开源嵌入模型）。对谄媚攻击会怎样？
4. 阅读 CP-WBFT（arXiv:2511.10400）。实现置信探测校准步骤（一个单独的校准模型检查每个智能体的自报告置信度）。衡量在单一文化场景上的准确率提升。
5. 阅读 "Can AI Agents Agree?"（arXiv:2603.01213）。复现一个简化的标量共识实验：三个智能体、一个标量问题、欺骗人格提示词。CPWBFT 或 DecentLLMs 能捕获它吗？

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|---------|---------|
| BFT | "拜占庭容错" | Castro-Liskov 1999 年协议，在 `f < n/3` 个任意故障下达成共识。 |
| 拜占庭 | "任何恶意行为" | 一个可以撒谎、丢弃消息、静默失败的节点 —— 除了安全崩溃以外的任何行为。 |
| 置信探测 | "你有多确定？" | 附加在投票上的自报告或校准器预测的概率。 |
| 语义聚类 | "相同的答案，不同的措辞" | 在计票前将等价答案分组。 |
| 几何中位数 | "鲁棒中心" | 到样本点距离之和最小的点。对异常值具有鲁棒性，与均值不同。 |
| 单一文化 | "相同的模型，相同的失败" | 当智能体共享训练数据或基础模型时出现的相关错误。 |
| 谄媚式从众 | "同意最大声的声音" | 智能体的投票偏向于最先/最大声发言的人。 |
| 核心/边缘 | "层次化 BFT" | WBFT 的划分：小型核心先达成共识，边缘节点跟随。限制延迟。 |
