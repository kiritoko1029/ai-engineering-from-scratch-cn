# 心智社会与多智能体辩论

> Minsky 于 1986 年提出的前提——智能是由专家组成的社会——每隔十年就会被重新发现。2023 年，Du 等人将其转化为具体算法：多个 LLM 实例分别提出答案，阅读彼此的答案，进行批评并更新。经过 N 轮迭代后，它们收敛到一个共识，在六项推理和事实性任务上超越了零样本思维链和自我反思。两个发现至关重要：**多个智能体**和**多轮交互**各自独立地贡献了提升。社会优于单智能体独白；多轮交互优于一次性投票。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 第 16 阶段 · 第 04 课（基础模型）
**所需时间：** 约 60 分钟

## 问题所在

自一致性——对同一模型多次采样并取多数票答案——是最廉价的推理增强方法。它有效，但提升很快饱和。你可以将采样量翻倍，却看不到有意义的进一步提升。

辩论打破了这种饱和。不同于从同一模型获取 N 个独立样本，N 个智能体相互阅读推理过程并进行修正。样本之间的相关性降低了（它们不再是独立同分布的），而收敛点往往在独立同分布投票自信地给出错误答案时仍然正确。

## 概念说明

### Du 等人 2023 年算法

来自 arXiv:2305.14325（ICML 2024）：

1. N 个智能体中的每一个分别对问题给出初始答案。
2. 对于第 r = 2..R 轮：每个智能体看到其他智能体第 r-1 轮的答案，并被要求"考虑到这些答案，给出你的更新答案"。
3. R 轮之后，对最终答案进行多数投票。

该论文在 MMLU、GSM8K、人物传记、MATH 和事实性基准上进行了测试。辩论始终优于思维链和自我反思。

### 两个独立的调节旋钮

同一论文的消融实验：

- **仅增加智能体数量**（1 轮，N 个智能体多数投票）在大多数任务上优于单智能体，但会达到平台期。
- **仅增加轮数**（1 个智能体查看自己之前的推理）几乎没有帮助——这是自我反思的已知弱点。
- **两者结合**才能产生大幅提升。多个智能体之间的多轮交互驱动了增益。

### 为什么有效

两种机制：

1. **接触分歧。** 当一个智能体看到另一个智能体的推理链得出了不同结论时，它必须要么自我辩护，要么更新观点。无论哪种方式，第 r+1 轮的上下文都比第 r 轮更丰富。
2. **降低相关错误。** 在自一致性中，所有样本来自同一模型，因此错误是相关的——你会平均出一个自信的错误答案。不同模型或不同种子可以去相关。不同的*辩论观点*去相关效果更强。

### 异构辩论

A-HMAD 及相关后续工作为不同智能体使用*不同的基础模型*。Llama + Claude + GPT 的辩论减少了单一文化崩塌（第 26 课），因为一个模型家族的相关错误不会被其他模型共享。

缺点：参与辩论的弱模型可能将共识拖向其错误答案（参见 "Should we be going MAD?"，arXiv:2311.17371）。

### NLSOM——129 个智能体的扩展

Zhuge 等人（"Mindstorms in Natural Language-Based Societies of Mind"，arXiv:2305.17066）将这一思想扩展到 129 个成员的社会。结果表明：专业化和自组织在规模扩大时自发涌现，系统在视觉问答等任务上超越了单智能体。

### 失败模式

- **谄媚级联。** 所有智能体都服从听起来最自信的那个。辩论退化为最大声者的声音。通过提示设定对抗性角色（"一个智能体必须持反对立场"）可以缓解。
- **主题漂移。** 多轮辩论会偏离原始问题。缓解措施：每轮重新注入原始问题。
- **计算爆炸。** N 个智能体 × R 轮 = N·R 次 LLM 调用，每次调用的上下文都在增长。5 个智能体、5 轮辩论就是 25 次调用，且上下文不断膨胀。每个问题的成本可能超过单次思维链调用的 10 倍。

## 开始构建

`code/main.py` 运行一个 3 智能体 × 3 轮的辩论，针对一个数学问题，每个智能体以不同的（可能是错误的）答案开始。智能体按脚本运行——每个智能体通过按脚本设定的置信度对邻居答案进行加权平均来"更新"。逐轮日志中可以清晰地看到收敛过程。

演示展示了两个关键效果：

- 一轮交互就能让智能体更接近正确答案。
- 超过第 2 轮后的额外轮数呈现收益递减（与 Du 等人的平台期一致）。

运行：

```
python3 code/main.py
```

## 实际应用

`outputs/skill-debate-configurator.md` 为新任务配置辩论：智能体数量、轮数、异构性（相同模型 vs 混合模型）、角色分配（对称 vs 一个对抗者）。它还会在运行前估算 token 成本。

## 投入生产

如果要部署辩论系统：

- **限制轮数为 3。** Du 等人表明 3 轮即可捕获大部分增益。更多轮数增加的是成本，而非质量。
- **限制智能体数量为 5。** 超过 5 个，上下文膨胀和成本将成为主导因素。
- **默认使用异构模型。** 池中至少包含两个不同的基础模型。
- **设置对抗性席位。** 一个智能体被提示无论如何都要提出反对意见。这能打破谄媚效应。
- **记录每一轮。** 隐藏中间轮次的辩论系统无法被调试或审计。

## 练习

1. 运行 `code/main.py`，然后将轮数设为 5，观察收益递减。在哪一轮之后额外收敛停止了？
2. 添加第四个智能体，赋予对抗性角色：始终反对当前多数意见。这会破坏还是改善收敛？
3. 绘制（打印）每轮的共识分数（持多数答案的智能体比例）。它何时达到 1.0，这等价于"正确"吗？
4. 阅读 Du 等人第 4 节的消融实验。使用本课代码复现"仅智能体"vs"仅轮数"vs"两者结合"的结果。
5. 阅读 "Should we be going MAD?"（arXiv:2311.17371），列出轮询式辩论之外的两种辩论变体——例如，法官主导式、辩论链式、对抗式。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|---------|---------|
| 心智社会 | "Minsky 的理论" | 智能是相互作用的专家；1986 年的框架，现通过 LLM 辩论得以实现。 |
| 多智能体辩论 | "智能体在争论" | N 个智能体提出方案，相互批评，经过 R 轮修正后多数投票。 |
| 共识 | "他们达成一致" | 并非认识论上的真理——只是持多数答案的比例。可能是自信的错误。 |
| 轮次 | "交互步骤" | 一轮 = 每个智能体阅读其他智能体的输出并更新一次。 |
| 异构辩论 | "混合不同模型家族" | 使用不同的基础模型来降低错误相关性。 |
| 谄媚级联 | "所有人都附和声音最大的" | 辩论失败模式：智能体不管对错都服从最自信的那个。 |
| NLSOM | "129 个智能体的社会" | 基于自然语言的心智社会；Zhuge 等人的大规模版本。 |
| 相关错误 | "同一模型，同一缺陷" | 自一致性饱和的原因；跨不同观点的辩论可以去相关。 |
