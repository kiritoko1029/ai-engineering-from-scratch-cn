# 智能体经济、代币激励与声誉

> 长周期自主智能体（METR 的 1 小时至 8 小时工作曲线）需要经济自主能力。新兴的**五层架构栈**为：**DePIN**（物理算力）→ **身份**（W3C DID + 声誉资本）→ **认知**（RAG + MCP）→ **结算**（账户抽象）→ **治理**（智能体 DAO）。生产级智能体激励网络包括 **Bittensor**（TAO 子网奖励特定任务模型）、**Fetch.ai / ASI Alliance**（ASI-1 Mini LLM + FET 代币）和 **Gonka**（基于 Transformer 的工作量证明，将算力重新分配给生产性 AI 任务）。学术研究方面：AAMAS 2025 的去中心化 LaMAS 使用 **Shapley 值信用归因**来公平奖励贡献智能体；Google Research 的"大语言模型机制设计"提出了在单调聚合下使用**代币拍卖**和二阶价格支付的方案。本课将构建一个最小化智能体市场，将 Shapley 值信用归因应用于多智能体流水线，并运行二阶价格代币拍卖，使博弈论机制落地为具体实践。

**类型：** 学习
**语言：** Python（标准库）
**前置要求：** Phase 16 · 16（协商与议价）、Phase 16 · 09（并行群体网络）
**所需时间：** 约 75 分钟

## 问题

当多个智能体共同创造价值但需要分别获得奖励时，多智能体系统会变得复杂。经典机制——平均分配、最后贡献者独占——既不公平也容易被利用。基于联盟的 Shapley 值奖励在构造上是公平的，但计算成本很高。2025-2026 年的文献推动了实用的近似方法：Shapley 采样、单调聚合拍卖，以及从已确认贡献中累积的链上声誉。

在信用归因之外，该领域已转向实际的经济智能体：Bittensor TAO 奖励挖矿算力来微调子网特定模型，Fetch.ai/ASI 用 FET 代币奖励 ASI-1 Mini LLM 的使用，Gonka 将 Transformer 工作量证明重新分配给生产性 AI 任务。能够自主交易的智能体已经存在；问题在于如何对齐激励。

本课将智能体经济视为一个特定的问题族——信用归因、机制设计和声誉——并用最小化的数学来构建每个模块，使概念深入人心。

## 概念

### 五层智能体经济架构栈

1. **DePIN（物理算力）。** 去中心化基础设施，提供 GPU、存储、带宽的租赁。Bittensor 子网、Render Network、Akash。并非智能体专属；智能体使用它。
2. **身份。** W3C 去中心化标识符（DID）为每个智能体提供独立于任何平台的持久身份。声誉累积到 DID 上。智能体网络协议（ANP）使用 DID 作为发现层。
3. **认知。** 智能体的推理循环：LLM + RAG + MCP。这是其他阶段所构建的内容。
4. **结算。** 账户抽象（ERC-4337）让智能体可以从自身余额中支付 Gas 费，无需持有 ETH。智能体可以为服务、彼此之间或算力进行支付。
5. **治理。** 智能体 DAO：人类*和*智能体共同对协议变更进行投票的治理结构，投票权与声誉挂钩。

并非每个生产系统都使用全部五层。Bittensor 使用第 1、2 层，部分使用第 3、4 层，不使用第 5 层。OpenAI 智能体仅使用第 3 层。该架构栈是参考地图，而非硬性要求。

### Bittensor、Fetch.ai、Gonka——运行中的系统

**Bittensor（TAO）。** 子网是专门的任务（语言建模、图像生成、预测）。矿工提交模型输出。验证者进行排名；基于质押权重的评分分配 TAO 奖励。每个子网有独立的评估方式。经济学启示：为任务特定的输出质量付费，而非为使用的算力付费。

**Fetch.ai / ASI Alliance。** ASI-1 Mini LLM 运行在 Fetch.ai 网络上；用户使用 FET 代币支付推理费用。智能体作为对等节点的叙事在这里更为突出：Fetch 上的智能体可以调用另一个智能体完成任务并用 FET 支付。

**Gonka。** Transformer 工作量证明："工作"是 Transformer 的前向传播。矿工通过运行具有已知正确输出（来自训练数据）的推理任务来赚取收益。资源生产性的工作量证明，而非基于哈希的工作量证明。

截至 2026 年 4 月，三者均为生产级系统。收益分配方式不同。Bittensor 奖励相对于子网验证者的质量；Fetch 奖励由付费用户衡量的实用性；Gonka 奖励可验证的推理工作。

### Shapley 值信用归因

三个智能体协作完成一项任务。输出评分为 0.8。谁贡献了什么？

Shapley 值：满足四个公理（效率性、对称性、线性性、零性）的唯一信用分配方案。对于智能体 `i`：

```
shapley(i) = (1/N!) * sum over all orderings O of (v(S_i_O ∪ {i}) - v(S_i_O))
```

其中 `S_i_O` 是排序 `O` 中 `i` 之前的智能体集合。实际操作中：枚举所有排列，记录每个排列中每个智能体的边际贡献，然后取平均值。

对于 N=3 个智能体，有 6 种排列。对于 N=10，有 360 万种——因此在实践中通常采样排列而非穷举。

### 二阶价格聚合拍卖

Google Research（"大语言模型机制设计"）提出使用二阶价格代币拍卖来聚合 LLM 输出。设定：N 个智能体各自提出一个补全结果；每个智能体对被选中有一个私有估值。拍卖者选择最高估值的提案，支付*第二高*的价格。在单调聚合下（价值取决于选择了哪个提案，而非投标数量多少），这是诚实激励的——智能体会如实报出自己的真实估值。

这对 LLM 系统的意义在于：你可以将补全任务外包给多个具有不同定价的智能体；拍卖选出最佳方案并公平支付，智能体没有虚报的动机。

### 声誉资本

与 DID 绑定的声誉分数从已确认的贡献中累积。一个简单的更新规则：

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

其中衰减因子 `alpha` 接近 1。声誉：

- 读取成本低，可用于路由决策（"将困难任务分配给高声誉智能体"）。
- 伪造成本高（随时间累积，绑定到 DID）。
- 可被削减：未通过验证的贡献会被扣除。

### AAMAS 2025 去中心化 LaMAS

LaMAS 提案（AAMAS 2025）结合了：DID 身份、Shapley 值信用归因和简单拍卖机制。核心主张：去中心化信用归因步骤使系统可审计且免受单点操纵。

### 经济机制失效的场景

- **价格预言机操纵。** 如果信用函数可以被利用，智能体就会去利用它。每个机制都需要对抗性测试。
- **女巫攻击。** 一个运营者启动 N 个虚假智能体来夸大自己的贡献。DID 可以减缓但无法阻止；声誉的伪造成本是缓解手段。
- **验证成本。** 信用归因的公平性取决于验证者。如果验证成本低（小型 LLM），容易被利用；如果成本高（人工评审），系统无法扩展。
- **监管风险。** 智能体经济与金融监管交叉。截至 2026 年，Bittensor、Fetch 和 Gonka 在某些司法管辖区均处于法律灰色地带。

### 智能体经济适用的场景

- **异构运营者的开放网络。** 没有单一团队控制所有智能体。
- **可验证的输出。** 没有验证，信用归因就是猜测。
- **长周期工作流。** 一次性任务无法从声誉累积中获益。
- **代币化支付在你的司法管辖区具有法律可行性。**

在封闭的企业系统中，经济机制让位于更简单的分配方式（管理者分配工作，指标是内部的）。经济学文献主要适用于开放网络。

## 投入生产

在 2026 年运行智能体经济：

- **从声誉开始，而非代币。** 声誉实现成本低且本身就有价值；代币会增加法律和经济复杂性。
- **先验证再奖励。** 在没有独立验证步骤的情况下永远不要分配信用。自报质量会招致女巫攻击。
- **Shapley 采样，而非精确 Shapley。** 采样 100-1000 个排列；精确枚举无法扩展。
- **设定衰减因子上限和声誉下限。** 无限制的衰减会抹除合法贡献者；过慢的衰减会奖励过时的高声誉智能体。
- **对抗性审计机制。** 在开放网络之前运行红队场景。每个机制都有博弈论；你要找的是漏洞，而非攻击者。
