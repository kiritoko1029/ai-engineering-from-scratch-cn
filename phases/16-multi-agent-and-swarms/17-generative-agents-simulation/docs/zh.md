# 生成式智能体与涌现模拟

> Park等人2023年（UIST '23，arXiv:2304.03442）在**Smallville**这个包含25个智能体的沙盒中，采用了三部分架构：**记忆流**（自然语言日志）、**反思**（智能体对自身记忆流生成的更高层次综合）和**计划**（日级行为，再细化为子计划）。标志性的成果是情人节派对的涌现：一个被设定为"想举办情人节派对"的智能体，在没有进一步脚本的情况下，发出的邀请在群体中传播，协调了时间，派对最终成功举办——来自最初对此一无所知的24个智能体。消融实验证明三个组件对可信度都不可或缺。已记录的失败模式包括空间规范错误（进入已关门的商店、共用单人卫生间）。这是2026年智能体模拟和多智能体社会评估的参考架构。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** Phase 16 · 04（原始模型），Phase 16 · 13（共享记忆）
**所需时间：** 约75分钟

## 问题

大多数多智能体系统是紧密脚本化的团队：规划者规划，编码者编码，审查者审查。这对于定义明确的任务很有效。但它无法捕捉当智能体拥有记忆、优先级和开放世界时所产生的涌现式、非脚本化行为。研究、社会模拟以及越来越多的游戏AI需要这第二种能力。

Smallville架构就是这方面的基准。在Park 2023之前，最好的智能体模拟只是浅层的脚本跟随者；此后，该模式成为开放世界中生成式智能体的默认方案。如果你在2026年构建智能体模拟，你要么使用Smallville的三个组件，要么明确说明为什么不使用。

## 概念

### 三个组件

**记忆流。** 一个仅追加的日志，记录观察、行动、反思和计划。每条记录都有时间戳、类型、描述（自然语言），以及派生元数据：**时效性**、**重要性**（智能体自评1-10分）和**相关性**（与当前查询的余弦相似度）。

```
[2026-02-14 09:12:03] observation: Isabella Rodriguez asked me if I like jazz
[2026-02-14 09:14:22] reflection:   I enjoy long conversations about music
[2026-02-14 10:05:00] plan:         Attend Isabella's Valentine's Day party tonight
```

记忆检索综合三个分数：`score = w_recency * e^(-decay * age) + w_importance * importance + w_relevance * cos_sim`。排名靠前的条目进入当前提示。

**反思。** 定期地（每N条记忆或在重要事件发生时），智能体从近期记忆中生成更高层次的综合。反思条目被写回记忆流，可以像其他记忆一样被检索。这就是智能体构建"理解"的方式——该架构中长期信念的等价物。

**计划。** 自上而下的分解。首先，日级计划以大致轮廓展开（"去上班，和Klaus共进晚餐"）。然后是小时级计划。再然后是行动级计划。计划是可修订的：当观察与计划矛盾时，智能体仅重新规划受影响的部分。

### 为什么三个组件都不可或缺（消融实验）

Park等人进行了分别去掉观察、反思和计划的消融实验。每次消融都会损害可信度：

- 没有**观察**，智能体会错过上下文，基于过时的信念行动。
- 没有**反思**，智能体无法形成更高层次的信念；交互停留在浅层。
- 没有**计划**，行为变成反应式噪音；目标逐渐消散。

人类评分者的可信度分数在三者齐全时最高；去掉任何一个都会产生可衡量的退化。

### 情人节涌现事件

一个智能体，Isabella Rodriguez，被设定为目标"想在2月14日下午5点在Hobbs咖啡馆举办情人节派对"。其余24个智能体没有收到这样的设定。在模拟天数中：

1. Isabella的计划包含了邀请他人。
2. 每次邀请都成为邻居记忆流中的一条观察。
3. 那个邻居的反思生成了信念："Isabella要举办派对。"
4. 邻居的计划纳入了"2月14日参加派对"。
5. 邻居告诉其他邻居。邀请在没有中央协调的情况下传播开来。
6. 2月14日下午5点，多个智能体汇聚到Hobbs咖啡馆。

这是技术意义上的涌现：系统级行为（派对）从局部交互（双边邀请 + 个体计划）中产生，没有中央编排者。

### 已记录的失败模式

Park等人明确记录了：

- **空间规范错误。** 智能体走进已关门的商店。智能体试图共用单人卫生间。智能体在不适合用餐的房间吃饭。模型无法仅从环境中推断社会物理规范。
- **记忆溢出。** 深度模拟运行导致记忆检索成本增长。实际对策：定期记忆压缩（摘要-修剪）和对低重要性条目施加衰减。
- **反思幻觉。** 反思可能发明记忆流中不存在的关系。缓解措施：在反思提示中包含源记忆ID，并在检索时验证。

这些是生产环境中相关的失败模式：任何2026年的智能体模拟都会继承它们。

### 三组件实现规则

1. **记忆是仅追加的。** 永远不要修改记忆条目。纠正是新的条目。
2. **重要性评分成本低廉。** 在写入时调用大语言模型对重要性进行1-10分评级。缓存该分数。
3. **检索是排序式的，而非过滤式的。** 按综合分数取Top-k；不要使用硬过滤（会丢失上下文）。
4. **反思定期运行。** 当未处理记忆的重要性总和超过阈值（如150）时触发。
5. **计划是可修订的。** 当新的观察与计划矛盾时，仅重新生成受影响的部分，而非整个计划。

### 超越Smallville的生成式智能体

2024-2026年的后续文献扩展了该架构：

- **用于政策/市场研究的多智能体社会模拟。** 类似Smallville的群体模拟用户对功能的反应。比A/B测试更快；准确性存在争议。
- **游戏NPC AI。** 使用Smallville智能体的RPG产生涌现式故事情节，而非脚本化的任务。
- **生成式智能体评估基准。** 指标不再是任务准确率，而是可信度 + 长时间运行中行为的一致性。

该架构是参考标准。扩展版本替换组件（向量存储替代记忆、检索增强反思、神经符号计划），但保留三部分结构。

### 为什么这对多智能体工程很重要

Smallville证明了当组件正确时，多智能体涌现是低成本的。该架构现已在开源模型上复现（较小的大语言模型在可信度上优雅退化，而非急剧下降）。任何需要**涌现式社会行为**的生产系统都采用这种形态。任何需要**紧密任务执行**的系统都使用本阶段前面介绍的监督者/角色/原始模式。

## 开始构建

`code/main.py` 用标准库Python实现了三个组件，使用脚本化的智能体策略（无真实大语言模型）。演示在微型规模下复现了情人节派对涌现：

- `MemoryStream` — 仅追加日志，支持时效性/重要性/相关性检索。
- `reflect(stream)` — 对近期高重要性记忆的脚本化反思。
- `plan(agent_state)` — 基于当前信念的日级和小时级计划。
- 场景：5个智能体。智能体1初始设定为"下午5点举办派对"。在模拟时钟推进过程中，邀请传播开来，智能体汇聚。

运行：

```
python3 code/main.py
```

预期输出：逐时钟的追踪记录。到最后一个时钟时，5个智能体中至少3个在其计划中显示派对，并且它们汇聚到派对地点。单一种子在没有任何编排者的情况下产生了协调到达。

## 实际应用

`outputs/skill-simulation-designer.md` 设计一个生成式智能体模拟：智能体数量、记忆模式、反思频率、计划视界和评估指标。

## 投入生产

生产环境模拟规则：

- **记忆就是数据库。** 在规模上选择真正的存储（向量数据库、Postgres）。内存标准库仅适用于原型。
- **记录检索轨迹。** 对于每个行动，记录驱动它的Top-k记忆。这是你的调试能力。
- **为每个智能体的token预算。** 每个智能体每时钟的检索 + 反思 + 计划是O(k)次大语言模型调用。N个智能体 × T个时钟 × 每时钟调用次数可能远超你的预算。
- **定期压缩记忆。** 对低重要性条目进行摘要-修剪。保留策略是设计决策，而非细节。
- **显式检测空间/社会规范违规。** 该架构不会自动学习这些规范。

## 练习

1. 运行`code/main.py`。确认3个以上智能体汇聚到派对。将智能体增加到10个——涌现是否仍然发生？
2. 去掉反思步骤。行为会变成什么样？对照Park 2023的消融发现。
3. 引入一个竞争性的种子目标（"Klaus想在下午5点做研究报告"）。智能体会分裂，还是一个目标占主导？什么因素决定了结果？
4. 添加空间约束：Hobbs咖啡馆最多容纳4个智能体。模拟是否优雅地处理溢出，还是会触及"单人卫生间"的失败模式？
5. 阅读Park等人（arXiv:2304.03442）第6节（涌现行为实验）。找出一个在你的微型模拟中无法复现的行为。需要增强架构的哪个组件？

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------------|------------------------|
| 记忆流 | "智能体的日记" | 观察、行动、反思、计划的仅追加日志。 |
| 时效性 | "记忆有多新" | 按时间衰减的指数衰减分数。 |
| 重要性 | "智能体有多在意" | 写入时自评1-10分。已缓存。 |
| 相关性 | "与当前查询有多相关" | 余弦相似度（基于嵌入）。 |
| 反思 | "更高层次的信念" | 从近期记忆生成的综合，作为新记忆重新摄入。 |
| 计划 | "日/小时/行动分解" | 自上而下的计划树。当观察矛盾时可修订。 |
| Smallville | "Park 2023的沙盒" | 产生了情人节涌现事件的25智能体模拟。 |
| 可信度 | "质量指标" | 人类评分者对行为是否像一个合理智能体的评分。 |
