# 投票、自一致性与辩论拓扑

> 最廉价的聚合方式：采样 N 个独立智能体，多数投票。Wang 等人 2022 年的自一致性用一个模型采样 N 次实现了这一点。多智能体将其扩展为**异构**智能体以摆脱单一文化 —— 不同模型、不同提示词、不同温度、不同上下文。在多数投票之上，辩论拓扑很重要：MultiAgentBench（arXiv:2503.01935，ACL 2025）评估了星形/链形/树形/图的协调方式，发现**图在研究任务上表现最佳**，超过约 4 个智能体后出现"协调税"。AgentVerse（ICLR 2024）记录了两种涌现模式 —— 志愿者行为和从众行为 —— 从众既是特性（达成共识）也是风险（群体思维，第 24 课）。本课映射拓扑空间，构建每种变体，并衡量协调税。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 第 16 阶段 · 07（心智社会与辩论），第 16 阶段 · 14（共识与 BFT）
**所需时间：** 约 75 分钟

## 问题

辩论可以提高准确率（Du 等人，arXiv:2305.14325）。也可能降低。辩论是否有帮助取决于四个结构性选择：

1. 谁跟谁说话（拓扑）。
2. 多少轮（Du 2023：轮次和智能体数量独立地各自重要）。
3. 智能体是否异构（不同的基础模型打破单一文化）。
4. 是否存在对抗性声音（强化论证 vs. 稻草人论证）。

在任务上直接叠加"运行 5 个智能体然后投票"的团队往往会比单个智能体退步。失败不是随机的。它们与拓扑和异构性相关。本课就是拓扑地图。

## 概念

### 自一致性，单模型基线

Wang 等人 2022（"Self-Consistency Improves Chain of Thought Reasoning"）在温度 > 0 时对同一模型采样 N 次，并对推理路径答案进行多数投票。在 GSM8K 上的结果：N=40 个样本相比单次贪婪解码有显著提升。自一致性是多智能体投票的单智能体前身。

局限：自一致性使用一个基础模型。错误在构造上就是相关的。如果模型有系统性偏差，所有 N 个样本都共享它。

### 多智能体投票，异构扩展

用 N 个*不同的*智能体替换 N 个样本。不同的基础模型（Claude、GPT、Llama）、不同的提示词、不同的工具访问。好处：错误不相关。代价：不同智能体成本不同；协调它们增加开销。

异构辩论在 2026 年的典型名称是 **A-HMAD** —— 对抗性异构多智能体辩论。虽然没有被普遍采用，但论文用这个术语表示"不同模型辩论，减少单一文化坍缩带来的相关错误"。

### 四种拓扑

```
star                chain               tree                graph

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           (fully connected)
```

星形：一个中心，其他所有节点只与中心通信。等同于没有反馈通道的监督者-工作者模式。
链形：线性，每个智能体看到前一个的输出。类似流水线。
树形：层次结构，用于层次化智能体系统（第 06 课）。
图：任意对等通信。包括全连接团和任意 DAG。

### 协调税（MultiAgentBench）

MultiAgentBench（MARBLE，ACL 2025，arXiv:2503.01935）在包括研究、编码和规划的任务套件上对星形、链形、树形、图进行了基准测试。关键测量结果：

- **图**拓扑在研究任务上胜出。信息任意对等流动；智能体可以互相批评。
- **星形**在快速回答的事实任务上胜出。中心过滤和整合。
- **链形**在逐步流水线（分阶段精炼）上胜出。
- **协调税**在图拓扑中超过约 4 个智能体后出现。挂钟时间和 token 成本增长快于质量。

4 个智能体的上限是经验性的，而非根本性的。它反映了 2026 年 LLM 的上下文容量：每个智能体的上下文填满了对等方的输出，一旦每个人都能看到所有人，增加第 N+1 个智能体的边际价值就下降了。

### 多智能体辩论策略（"我们应该使用 MAD 吗？"）

arXiv:2311.17371 是 2023 年的 MAD 策略综述。被他人重复验证的关键发现：与自一致性*结构相似*的 MAD 变体（独立采样 + 聚合）在相同预算下往往不如自一致性。MAD 在智能体真正异构且辩论具有对抗性结构（一个智能体提出反对意见）时帮助最大。

### AgentVerse 涌现模式

AgentVerse（ICLR 2024，https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf）记录了即使没有显式设计也会从多智能体辩论中涌现的两种行为：

- **志愿者。** 一个智能体主动提供帮助（"我可以做下一步"）。有用：它将工作分配给最适合子任务的智能体。
- **从众。** 一个智能体调整其立场以迎合批评者，即使批评者是错的。这是辩论中的谄媚等价物（第 14 课）。

从众是为什么"辩论直到达成一致"会奖励霸凌者的原因。限制轮次加上单独的裁判可以缓解。

### 异构性：真正提升准确率的旋钮

2024-2026 年实用文献中的一个模式：将 N 个智能体中的一个换成不同的基础模型，比增加一个 N 带来的准确率提升更大。直觉是单一文化 —— 每个新的独立错误源比一个额外的相关样本更有价值。

在极限情况下，异构性胜过数量。三个不同的模型在大多数有清晰真实答案的任务上胜过一个模型的五个副本。

### 陪审团方法

Sibyl 框架（在 Minsky-LLM 文献中引用）形式化了"陪审团" —— 一组小型专家智能体，通过在每个阶段投票来精炼答案。与普通多数投票不同，陪审团有角色分工：一个智能体交叉询问，一个提供上下文，一个评分可信度。陪审团方法介于普通投票（廉价、易受单一文化影响）和完整 MAD（昂贵、易受从众影响）之间。

### 投票加辩论何时占优

- 问题有真实答案（事实、数学、代码行为）。投票收敛是有意义的。
- 智能体可以访问不同的来源或工具（可获得异构性）。
- 轮次有限（通常 2-3 轮）且有单独的裁判或验证器。
- 预算允许 3-5 个智能体。在图拓扑中超过 5-7 个，协调税占主导。

### 投票加辩论何时有害

- 问题是意见型的。智能体收敛到看起来最自信的答案，而不是最正确的答案。
- 所有智能体共享一个基础模型。单一文化使共识毫无意义。
- 轮次无限制。从众每次都赢。
- 任务很简单。单个智能体用 N=5 的自一致性更便宜且同样准确。

## 开始构建

`code/main.py` 实现了：

- `run_star(agents, hub, question)` — 中心轮询每个工作者，聚合。
- `run_chain(agents, question)` — 顺序精炼。
- `run_tree(root, children, question)` — 带深度 2 聚合的层次结构。
- `run_graph(agents, question, rounds)` — 全对等辩论，限制轮次。
- 一个脚本化的异构性调节器：每个智能体有一个 `error_bias` 表示其系统性错误方向。
- 一个测量工具，在 N=3、5、7 下运行每种拓扑并报告（准确率、总 token、模拟挂钟时间）。

运行：

```
python3 code/main.py
```

预期输出：拓扑 × N →（准确率、token、延迟）的表格。图在 N=3-5 的研究型任务上胜出；星形在快速事实任务上胜出；图在 N=7 时显示协调税（延迟膨胀快于准确率）。

## 实际应用

`outputs/skill-topology-picker.md` 是一个读取任务描述并推荐拓扑（星形/链形/树形/图）、N（智能体数量）、异构性配置（使用哪些基础模型）和轮次限制的技能。

## 投入生产

对于任何集成：

- 从**一个强大基础模型的 N=5 自一致性**开始。这是廉价基线。
- 如果准确率重要，升级到**N=3 的异构投票**。衡量差异。
- 只有在任务有结构（研究、多步骤）且轮次可行时才升级到**辩论拓扑**。
- 始终记录少数派集群。当少数派持续正确时，你有了多样性信号。
- 在衡量准确率的同时基准测试挂钟时间和 token。"10 倍成本换来更好准确率"是一个商业决策。

## 练习

3. 为图拓扑添加一个不投票、只对最终共识评分的"裁判"角色。这会改变涌现的从众行为吗？

5. 阅读 MultiAgentBench（arXiv:2503.01935）第 4 节（拓扑实验）。使用你的工具复现论文中一个任务的"图胜出研究"结果。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|---------|---------|
| 自一致性 | "采样 N 次，投票" | Wang 2022。单个模型，N 个温度 > 0 的样本，对推理路径进行多数投票。 |
| 异构性 | "不同的模型" | 不同基础模型或提示词系列的集成。打破单一文化。 |
| MAD | "多智能体辩论" | 智能体在多轮中交换批评的通用术语。参见 Du 2023。 |
| A-HMAD | "对抗性异构 MAD" | 强调不同模型 + 对抗性结构的 MAD 变体。 |
| 拓扑 | "谁跟谁说话" | 星形、链形、树形、图。决定信息流。 |
| 协调税 | "收益递减" | 在图拓扑中超过约 4 个智能体后，成本增长快于质量。 |
| 志愿者行为 | "主动帮助" | AgentVerse 涌现模式：一个智能体主动承担一个步骤。 |
| 从众行为 | "压力下的顺从" | AgentVerse 涌现模式：一个智能体迎合批评者。 |
| 陪审团 | "小型专家小组" | Sibyl 风格的带角色分工（审查者、上下文提供者、评分者）的集成。 |
