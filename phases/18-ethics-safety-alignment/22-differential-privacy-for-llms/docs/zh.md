# LLM 的差分隐私

> DP-SGD 仍然是标准——注入噪声的梯度更新提供正式的（epsilon, delta）保证。计算、内存和效用方面的开销相当大；参数高效的 DP 微调（LoRA + DP-SGD）是 2025 年的常见配置（ACM 2025）。两组证据存在张力：基于金丝雀的成员推断（Duan et al.，2024）报告对语言模型的成功率有限；训练数据提取（Carlini et al.，2021；Nasr et al.，2025）恢复了大量逐字记忆。2025 年 3 月的解释（arXiv:2503.06808）：差异在于测量对象——插入的金丝雀 vs "最可提取的"数据。新的金丝雀设计使基于损失的成员推断无需影子模型，并首次对在真实数据上以现实 DP 保证训练的 LLM 进行了非平凡的 DP 审计。替代方案：PMixED（arXiv:2403.15638）——通过下一词元分布上的专家混合在推理时进行私密预测；DP 合成数据生成（Google Research 2024）。新兴攻击：通过 LLM 反馈的差分隐私反转——置信度分数泄露。

## 问题所在

LLM 会记忆。Carlini et al. 2021 表明生产语言模型可以按需逐字再现训练文本。DP 是正式的防御手段：以可证明对任何单个训练样本不敏感的方式训练。2024-2025 年的证据表明 DP-SGD 是必要的，但已部署的 ε 值可能与威胁模型不匹配。

## 概念说明

### （ε, δ）-差分隐私

随机算法 M 是（ε, δ）-DP 的，如果对于任何相差一个样本的两个数据集和任何事件 S：
P(M(D) in S) <= e^ε * P(M(D') in S) + δ。

解释：输出分布足够接近（由 ε 参数化），使得任何单个个体的贡献不能被可靠推断，除非以概率 δ。

### DP-SGD

Abadi et al. 2016。标准方案：
1. 采样一个小批量。
2. 计算每个样本的梯度。
3. 将每个样本的梯度裁剪到阈值 C。
4. 对裁剪后的梯度求和并添加标准差为 σ * C 的高斯噪声。
5. 使用含噪总和更新参数。

隐私成本由记账器（矩记账器、Rényi DP 记账器）跟踪。LLM 文献中报告的 ε 值因威胁模型、数据敏感性和效用目标而差异很大；没有普遍"安全"的默认 ε。已发表的示例在某些 LLM 训练设置中大约在 ε ≈ 1–10 的范围内，但这些仅供参考——不是推荐的默认值。较低的 ε 通常需要更多噪声，并可能增加效用损失。

### LoRA + DP-SGD

对前沿模型进行完整的 DP-SGD 是不可行的。LoRA（Hu et al. 2022）将梯度更新限制在一个小型适配器中，减少了每个样本的梯度存储。LoRA + DP-SGD 是 2025 年的常见配置。DP 保证适用于适配器；基础模型保持固定。

### 2024-2025 年的张力

两组证据：

- **金丝雀 MIA（Duan et al. 2024）。** 向训练数据中插入唯一的金丝雀，测量成员推断攻击者能否识别它们。报告对语言模型的成功率有限。表明 MIA 很难。
- **训练数据提取（Carlini 2021，Nasr et al. 2025）。** 用前缀提示模型；测量它是否能从训练中恢复逐字文本。报告了大量记忆。表明 MIA 在相关意义上是容易的。

2025 年 3 月的解释（arXiv:2503.06808）：两者测量的是不同的东西。MIA 问的是"示例 e 是否在 D 中？"，针对插入的金丝雀。提取问的是"我能从 D 中恢复什么？""最可提取的"示例才是对隐私真正重要的；金丝雀低估了这一点，因为它们没有被优化为可提取的。

新的金丝雀设计。无需影子模型的基于损失的 MIA。首次对在真实数据上以现实 DP 保证训练的 LLM 进行了非平凡的 DP 审计。

### DP 训练的替代方案

- **PMixED（arXiv:2403.15638）。** 推理时的私密预测。在下一词元分布上进行专家混合；每个专家看到训练数据的一个分片；聚合时添加噪声以实现 DP。完全避免了 DP 训练。
- **DP 合成数据生成（Google Research 2024）。** 使用 DP-SGD 进行 LoRA 微调，采样合成数据，在合成数据上训练下游分类器。

两者都规避了完整 DP 训练的效用成本，代价是采用不同的威胁模型。

### 通过 LLM 反馈的差分隐私反转

2025 年新兴攻击。利用 DP 训练模型的置信度分数作为预言机来重新识别个体。即使输出不泄露信息，置信度分布也可能泄露。

防御措施：不要暴露置信度，或在暴露前截断/量化。这是（ε, δ）-DP 训练之外的额外要求。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|------------|----------|
| DP | "（ε, δ）-差分隐私" | 正式隐私：在相邻数据集变化下输出分布接近 |
| DP-SGD | "注入噪声的 SGD" | 梯度裁剪 + 高斯噪声添加；标准 DP 训练 |
| LoRA + DP-SGD | "高效私密微调" | 在低秩适配器上的 DP-SGD；2025 年的标准配置 |
| MIA | "成员推断" | 判断某个样本是否在训练数据中的攻击 |
| 金丝雀 | "插入的水印样本" | 用于测量 DP 泄露的唯一训练样本 |
| PMixED | "私密推理混合" | 通过下一词元分布上的专家混合实现推理时 DP |
| DP 反转 | "置信度泄露攻击" | 利用模型置信度作为预言机进行重新识别的攻击 |
