# StyleGAN

> 大多数生成器会同时将 `z` 混合到每一层中。StyleGAN 则采取了不同的方式：首先将 `z` 映射为中间变量 `w`，然后通过 AdaIN 在每个分辨率层级中*注入*该 `w`。正是这一改变让潜在空间变得结构清晰，使得生成逼真人脸成为了一个持续七年都已被解决的技术问题。

**类型：** 构建
**语言：** Python
**先修课程：** 第 8 阶段 · 03（GANs）、第 4 阶段 · 08（归一化）、第 3 阶段 · 07（CNNs）
**耗时：** 约 45 分钟

## 问题所在

DCGAN 通过一系列转置卷积将 `z` 映射为图像。存在的问题在于：`z` 控制着所有要素——姿态、光照、身份特征以及背景——这些要素彼此紧密关联。只要在 `z` 的某个维度上发生变化，其余四个维度也会随之改变。由于该表示方式无法分离出“相同人物但不同姿态”的特征，因此无法要求模型生成这样的图像。

Karras 等人（2019年，NVIDIA）提出了解决方案：不再直接将 `z` 输入到卷积层中，而是将一个大小为 `4×4×512` 的常量张量作为网络输入。随后训练一个包含8层的多层感知机，实现从 `z ∈ Z` 到 `w ∈ W` 的映射。通过*自适应实例归一化*（AdaIN）技术，在每个分辨率层级注入 `w`：首先对每个卷积特征图进行归一化，然后再通过 `w` 的仿射投影对其进行缩放和平移处理。此外，还会在每一层添加随机噪声，以生成诸如皮肤毛孔、头发丝等细节。

其结果便是 `W` 中形成了大致正交的轴，分别对应“高级风格”（如姿态、身份特征）与“精细风格”（如光照、颜色）。通过使用图像 A 的 `w` 作为低分辨率层的数据，再结合图像 B 的 `w` 作为高分辨率层的数据，即可在两幅图像之间切换风格。这一方法为图像编辑、跨领域风格化处理以及后续的“StyleGAN-inversion”系列研究奠定了基础。

## 概念概述

![StyleGAN：映射网络 + AdaIN + 每层噪声](../assets/stylegan.svg)

**映射网络。** `f: Z → W`，为一个8层的多层感知机。其中 `Z = N(0, I)^512`。`W` 不必是高斯分布——它会学习与数据特征相适应的形状。

**合成网络。** 从一个预定义的常量 `4×4×512` 开始构建。每个分辨率块的结构为：`上采样 → 卷积 → AdaIN(w_i) → 噪声注入 → 卷积 → AdaIN(w_i) → 噪声注入`。分辨率逐层翻倍，依次为 4、8、16、32、64、128、256、512、1024。

**AdaIN。**

```
AdaIN(x, y) = y_scale · (x - mean(x)) / std(x) + y_bias
```

其中，`y_scale` 和 `y_bias` 是通过对 `w` 进行仿射投影得到的。首先对每个特征图进行归一化，然后再进行“风格化”处理。“风格化”此处指的是特征图的一阶和二阶统计量。

**逐层噪声。** 在每个特征图中添加单通道高斯噪声，并通过一个学习得到的逐通道系数对其进行缩放。该方法可在不影响全局结构的情况下控制随机细节。

**截断技巧。** 在推理阶段，先采样 `z`，计算 `w = mapping(z)`，随后得到 `w' = ŵ + ψ·(w - ŵ)`，其中 `ŵ` 是多个样本中 `w` 的均值。参数 `ψ < 1` 是在多样性与质量之间所做的权衡。几乎所有的 StyleGAN 演示都使用 `ψ ≈ 0.7`。

## StyleGAN 1 → 2 → 3 版本演进

| 版本 | 发布年份 | 创新点 |
|---------|------|------------|
| StyleGAN | 2019 | 映射网络 + AdaIN + 噪声注入 + 逐步扩展机制。 |
| StyleGAN2 | 2020 | 采用权重解调技术替代AdaIN（消除水滴状伪影）；引入跳过/残差架构；添加路径长度正则化。 |
| StyleGAN3 | 2021 | 无别名卷积 + 等变核函数；避免纹理粘附在像素网格上。 |
| StyleGAN-XL | 2022 | 支持类别条件生成，分辨率为1024²，适用于ImageNet数据集。 |
| R3GAN | 2024 | 通过更强的正则化机制进行重新设计；参数量仅为Diffusion模型的1/20，却在FFHQ-1024分辨率下性能接近后者。 |

截至2026年，StyleGAN3依然是以下场景的默认选择：(a) 高帧率下的窄领域真实感生成；(b) 少样本域适应（仅需100张新数据集图像即可训练，同时冻结映射网络）；(c) 基于反演的编辑功能（寻找能够重构真实照片的权重参数`w`，进而对该参数进行修改）。而对于开放领域的文本到图像生成任务，它并非最佳工具——Diffusion模型才是。

## 构建它

`code/main.py` 实现了一个一维的简化版“style-GAN lite”模型：该模型包含一个映射多层感知机、一个合成函数（该函数接收一个已学习到的常量向量，并利用由 `w` 决定的缩放因子/偏置对其进行调节），以及每层的噪声机制。实验结果表明，通过仿射调制的方式注入 `w` 的效果，与将 `z` 直接拼接至生成器输入中的方式相当，甚至更为优异。

### 步骤 1：网络映射

```python
def mapping(z, M):
    h = z
    for i in range(num_layers):
        h = leaky_relu(add(matmul(M[f"W{i}"], h), M[f"b{i}"]))
    return h
```

### 步骤 2：自适应实例归一化

```python
def adain(x, w_scale, w_bias):
    mu = mean(x)
    sd = std(x)
    x_norm = [(xi - mu) / (sd + 1e-8) for xi in x]
    return [w_scale * xi + w_bias for xi in x_norm]
```

根据特征映射，缩放和偏置值通过线性投影从参数 `w` 中得出。

### 步骤 3：逐层噪声处理

```python
def add_noise(x, sigma, rng):
    return [xi + sigma * rng.gauss(0, 1) for xi in x]
```

每个通道的 Sigma 值是可学习的。

## 常见陷阱

- **水滴状伪影。** StyleGAN 1 由于 AdaIN 将均值置零，会在特征图中生成块状的水滴形结构。StyleGAN 2 则通过调整卷积权重来实现修复。
- **纹理粘连问题。** StyleGAN 1 和 StyleGAN 2 的纹理会跟随像素坐标而非物体坐标变化（在插值时尤为明显）。StyleGAN 3 采用无混叠的卷积方式，并结合窗口化的 sinc 滤波器来解决此问题。
- **模式覆盖范围。** 设置截断阈值 `ψ < 0.7` 虽能获得较为整洁的结果，但仅能从狭窄的锥形区域内采样；若需要更高的多样性，则应使用 `ψ = 1.0`。
- **逆向生成存在损失。** 将真实照片逆向转换为 `W` 通常需通过优化算法或编码器（如 e4e、ReStyle、HyperStyle）来实现。多次迭代后，生成结果会出现偏差。

## 使用它

| 使用场景 | 方法 |
|----------|----------|
| 真实感人脸（动漫风格、产品展示、窄脸） | StyleGAN3 FFHQ / 自定义微调 |
| 基于照片的人脸编辑 | e4e 反向变换 + StyleSpace / InterFaceGAN 方向控制 |
| 人脸替换/重演 | StyleGAN + 编码器 + 混合技术 |
| 化身生成流程 | 使用带 ADA 的 StyleGAN3 进行低数据量微调 |
| 基于少量图像的领域适配 | 冻结映射网络，仅微调合成模块 |
| 多模态或文本条件驱动的生成 | 不推荐 —— 应使用扩散模型 |

对于那些需要“人物面部照片”作为输入的产品级演示而言，在推理成本（单次前向传播，在 4090 显卡上耗时 <10ms）以及相同质量下的图像清晰度方面，StyleGAN 的表现优于扩散模型。

## 练习题

1. **简单。** 运行 `code/main.py`，分别设置 `adain_on=True` 和 `adain_on=False` 参数。对比在固定潜在向量与扰动后的潜在向量下生成的输出差异。
2. **中等难度。** 实现混合正则化机制：对于一个训练批次，计算 `w_a` 和 `w_b` 的值，在合成过程的前半部分使用 `w_a`，后半部分使用 `w_b`。解码器能否学习到相互独立的风格特征？
3. **高难度。** 使用预训练的 StyleGAN3 FFHQ 模型（ffhq-1024.pkl）。通过在带有标签的样本上训练 SVM 来找出控制“微笑”表情的 `w` 方向；并报告在避免身份信息漂移的前提下，该方向最多可以调整多远。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| 映射网络 | “MLP” | `f: Z → W`，共8层，用于将潜在几何结构与数据统计特征解耦。 |
| W空间 | “风格空间” | 映射网络的输出；各分量大致已解耦。 |
| AdaIN | “自适应实例归一化” | 先对特征图进行归一化，再通过`w`投影进行缩放和偏移处理。 |
| 截断技巧 | “Psi” | `w = mean + ψ·(w - mean)`，其中ψ<1，用于在多样性与质量之间取得平衡。 |
| 路径长度正则化 | “PL正则化” | 对每单位`w`变化带来的图像大幅变化施加惩罚，从而使`W`更加平滑。 |
| 权重解调 | “StyleGAN2的改进方案” | 对卷积权重而非激活值进行归一化，从而消除水滴状伪影。 |
| 无别名问题 | “StyleGAN3的技巧” | 使用窗口化的sinc滤波器，避免纹理粘附在像素网格上。 |
| 反向生成 | “为真实图像求解w” | 优化或编码`x → w`的关系，使得`G(w) ≈ x`。 |

## 生产注意事项：为何在2026年StyleGAN仍会被提供

在配备 4090 显卡的系统中，StyleGAN3 能在不到 10 毫秒的时间内生成 1024² 像素分辨率的 FFHQ 级别人脸图像——此时 `num_steps = 1`，且不进行 VAE 解码，也没有交叉注意力机制。从实际应用角度来看，这一时间即为任何图像生成器的最低延迟下限。而在相同分辨率下，采用 50 步骤的 SDXL 加 VAE 解码流程的耗时约为 3 秒。两者之间存在 **300 倍** 的差距；对于那些特定领域的产品（如头像服务、身份证明文件处理系统、库存人脸生成工具），StyleGAN3 在总体拥有成本方面更具优势。

由此带来的两个运营方面的影响如下：

- **无需调度器，也无需批处理机制。** 保持目标资源占用率下的静态批量处理即为最优方案。对于大型语言模型和扩散模型而言，虽然连续批处理是必不可少的，但在此类系统中并无任何好处，因为每个请求所需的浮点运算量都相同。
- **截断参数 `ψ` 即为控制样本方差的安全调节机制。** 当 `ψ < 0.7` 时，生成过程仅从映射网络输出范围中的狭窄锥形区域内采样。这是服务层控制样本方差的唯一手段：在负载高峰期可降低 `ψ` 值，而为高端用户则可提高该值。
