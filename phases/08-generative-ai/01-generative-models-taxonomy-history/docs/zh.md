# 生成模型——分类与历史发展

> 每个图像模型、文本模型、视频模型和3D模型都属于以下五类之一。如果选错了类别，你可能需要花费数周时间与复杂的数学公式作斗争；而一旦选对，该领域过去十二年的所有进展便能清晰地呈现在你的脑海中。

**类型：** 学习  
**语言：** Python  
**先修课程：** 第2阶段（机器学习基础）、第3阶段（深度学习核心）、第7·14阶段（Transformer模型）  
**时长：** 约45分钟

## 问题所在

生成模型仅承担一项任务：给定从某个未知分布 `p_data(x)` 中抽取的训练样本，输出看似同样来自该分布的新样本。无论是人脸、句子、MIDI文件还是蛋白质结构，仔细观察下来其实都属于同一类问题。

难点在于 `p_data` 位于一个拥有数百万维度的空间中（一张512x512分辨率的RGB图像大约有78.6万维度），而训练样本仅分布在该空间内的某个低维流形上，且我们通常只有约1000万个样本。试图直接计算该空间的密度是毫无希望的。每一种生成模型都是一种折中方案，通过用一个相对较容易解决的问题来替代另一个更难的问题。

在过去的十二年中，仅有五类生成模型得以存活。了解每一类模型所做出的折中选择，就能解释为何它们在某些任务上表现优异，而在其他任务上却表现不佳。

## 概念概述

![五类生成模型——按其建模对象划分的分类体系](../assets/taxonomy.svg)

**1. 显式密度，可处理型。** 将 `log p(x)` 表示为可直接计算的和式。自回归模型（PixelCNN、WaveNet、GPT）将 `p(x) = ∏ p(x_i | x_<i)` 分解开来。归一化流模型（RealNVP、Glow）则通过简单基函数的可逆变换来构建 `p(x)`。优点：似然函数精确，训练损失清晰；缺点：自回归推理为顺序处理方式（长序列时速度慢），且流模型需要可逆架构（对架构设计有限制）。

**2. 显式密度，近似型。** 通过下界约束 `log p(x)`（ELBO）并优化该下界。VAE（Kingma 2013）采用带有变分后验的编码器-解码器结构。扩散模型（DDPM、Ho 2020）则训练去噪器，以此隐式地优化加权后的 ELBO。截至 2026 年，扩散模型已成为图像、视频及 3D 领域的主流技术。

**3. 隐式密度型。** 完全跳过密度建模步骤；直接学习用于生成样本的生成器 `G(z)` 以及用于区分真伪的判别器 `D(x)`。即 GAN 模型（Goodfellow 2014）。此类模型推理速度快（仅需一次前向传播），但在训练过程中极不稳定。即便在 2026 年，StyleGAN 1/2/3 依然是在固定领域实现照片级真实感（如人脸、卧室场景）方面的最先进技术。

**4. 基于得分/连续时间型。** 直接学习对数密度函数的梯度 `∇_x log p(x)`（即得分函数）。Song 和 Ermon（2019）证明，得分匹配可将扩散模型推广为随机微分方程。流匹配技术（Lipman 2023）在 2024 至 2026 年间极为热门：它无需模拟过程，路径更平滑，采样速度比 DDPM 快 4 到 10 倍。Stable Diffusion 3、Flux、AudioCraft 2 等模型均采用流匹配技术。

**5. 基于令牌的离散码自回归型。** 先使用 VQ-VAE 或残差量化器将高维数据压缩为一系列简短的离散令牌序列，再利用 Transformer 模型来处理该令牌序列。Parti、MuseNet、AudioLM、VALL-E 以及 Sora 的补丁分词器均采用此方法。这实际上是在第一类模型基础上增加了自学习的令牌分词器。

## 五题筛选测试

当有新的生成模型论文发布时，在阅读方法部分之前，请先回答以下五个问题。

1. **正在建模的对象是什么？** 是像素、潜在变量、离散标记、3D高斯分布、网格还是波形？
2. **密度是显式的还是隐式的？** 作者是否明确给出了 `log p(x)` 的表达式？
3. **采样方式：一次性采样还是迭代采样？** 迭代采样会导致推理速度变慢；一次性采样通常对应对抗学习或蒸馏技术。
4. **条件设定：无条件、按类别、基于文本、基于图像，还是基于姿态？** 这些因素决定了损失函数及架构设计。
5. **评估指标是什么？** 是FID值、CLIP分数、IS值、人类偏好评分，还是任务准确率？每种指标都有其特定的失效模式（详见第14课）。

在本阶段的每一节课中，都需要重新回答这五个问题。经过反复练习后，这些问题的答案将变成你的条件反射。

## 构建它

本课的代码实现了一个轻量级的可视化示例：通过三种模拟方法（核密度法、离散直方图法以及基于最近样本的“类GAN”生成器）从样本中拟合一维高斯混合模型，以便让您在单屏显示的范围内直观地了解显式密度与隐式密度之间的差异。

运行 `code/main.py`。该脚本会从一个双模态高斯混合模型中生成2000个样本，随后输出如下内容：

```
explicit density (histogram): p(x in [-0.5, 0.5]) ≈ 0.38
approximate density (KDE):     p(x in [-0.5, 0.5]) ≈ 0.41
implicit (nearest-sample gen): 20 new samples printed, no p(x)
```

注意：前两种方法允许你询问“该点的概率是多少？”，而第三种则无法做到。这就是*显式与隐式*之间的区别，它将在后续的所有课程中都起到重要作用。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| 生成模型 | “它能创造新内容” | 学习 `p_data(x)` 的采样器，可选地提供 `log p(x)`。 |
| 显式密度 | “可以对其进行计算” | 模型提供封闭形式或可计算的 `log p(x)`。 |
| 隐式密度 | “类似 GAN 的” | 仅有采样器——无法计算给定点的 `p(x)`。 |
| ELBO | “证据下界” | `log p(x)` 的一个可计算下界；VAE 和扩散模型均以此为目标进行优化。 |
| 得分函数 | “对数密度的梯度” | `∇_x log p(x)`；扩散模型和随机微分方程模型会学习该场。 |
| 流形假设 | “数据存在于某个曲面上” | 高维数据集中在低维流形上，这也是降维有效的原因。 |
| 自回归 | “预测下一个元素” | 将联合分布分解为条件概率的乘积形式。 |
| 潜在表示 | “压缩后的代码” | 低维表示，解码器可利用其重建输入数据。 |

## 生产说明：五个系列，五种推理形态

每个模型家族对应不同的推理服务器成本曲线。现有关于生产环境推理的文献将大语言模型的推理过程视为预填充 + 解码；此处也采用相同的划分方式：

- **自回归模型（第1类和第5类）**：顺序解码是决定延迟的主要因素；KV缓存、连续批处理以及推测性解码等技术均可直接应用。
- **VAE / 扩散模型 / 流式匹配模型（第2类和第4类）**：不存在传统意义上的解码步骤。成本计算公式为 `num_steps × step_cost`，其中 `step_cost` 表示在完整潜在空间分辨率下进行一次Transformer或U-Net前向传播所需的成本。影响性能的关键参数包括步数（DDIM / DPM-Solver / 蒸馏技术）、批量大小以及精度（bf16 / fp8 / int4）。
- **GAN模型（第3类）**：仅需一次前向传播，没有调度机制，也不使用KV缓存。总延迟近似等于TTFT时间。这也是为什么在特定领域的用户体验方面，StyleGAN依然具有优势。

当在论文摘要中看到“比扩散模型更快”这样的表述时，应将其翻译为“步数更少且每步成本相同”或“步数相同但每步成本更低”。其余内容均为营销话术。
