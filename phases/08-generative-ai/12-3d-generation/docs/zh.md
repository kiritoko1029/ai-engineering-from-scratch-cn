# 3D 生成

> 3D 是二维到三维转换效果最显著的模态。2023 年的突破性技术为 3D 高斯溅射法。而在 2024 至 2026 年间，生成式技术则进一步发展出多视图扩散模型，并结合 3D 重建技术，能够仅通过一个提示词或照片即可生成物体与场景。

**类型：** 学习
**语言：** Python
**先修要求：** 第 4 阶段（视觉），第 8·07 阶段（潜在扩散模型）
**时长：** 约 45 分钟

## 问题所在

3D 内容的处理极具挑战性：

- **表示方式。** 网格、点云、体素网格、有符号距离场（SDF）、神经辐射场（NeRF）以及 3D 高斯分布。每种方法都有其各自的优缺点。
- **数据稀缺。** ImageNet 拥有 1400 万张图像。目前最大的高质量 3D 数据集（Objaverse-XL，2023 年发布）仅包含约 1000 万个对象，且大多数质量较低。
- **内存需求。** 一个 512³ 的体素网格包含 1.28 亿个体素；而一个实用的场景 NeRF 需要每条光线至少 100 万个采样点。3D 内容的生成难度远高于重建。
- **监督问题。** 对于 2D 图像，我们有像素作为直接数据；而对于 3D 内容，通常只有少量的 2D 视图，需要从中推断出 3D 结构。

2026 年的解决方案将这两个问题分开处理。首先，使用扩散模型生成*2D 多视图图像*；其次，基于这些图像拟合*3D 表示方式*（通常采用高斯溅射法）。

## 概念概述

![3D生成：多视图扩散模型 + 3D重建](../assets/3d-generation.svg)

### 表示方法：3D 高斯飞溅算法（Kerbl 等人，2023年）

将场景表示为约100万个3D高斯点云。每个高斯点包含59个参数：位置（3个）、协方差矩阵（6个，或由4个四元数加上3个缩放因子构成）、透明度（1个），以及球面谐波颜色信息（3阶为48个值，0阶为3个值）。

渲染过程 = 投影 + α混合。计算速度极快（在配备4090显卡的1080p设备上可达约100帧/秒）。该模型具备可微性，可通过梯度下降法根据真实照片进行参数拟合。在消费级GPU上，一个场景的拟合时间通常在5到30分钟之间。

在此基础上还有两项2023-2024年的创新技术：
- **生成式高斯点云技术**。如LGM、LRM、InstantMesh等模型能够直接根据一张或几张图像预测出相应的高斯点云。
- **4D高斯点云技术**。为动态场景中的高斯点赋予逐帧偏移量，以实现更复杂的视觉效果。

### 多视图扩散模型

通过微调预训练的图像扩散模型，可根据文本提示或单张图片生成同一物体的多个一致视图。相关模型包括 Zero123（Liu 等人，2023 年）、MVDream（Shi 等人，2023 年）、SV3D（Stability，2024 年）以及 CAT3D（Google，2024 年）。通常会生成物体周围的 4 到 16 个视图，并通过高斯溅射或 NeRF 技术将其提升为三维模型。

### NeRF（背景说明）

神经辐射场（Mildenhall 等人，2020年）。该技术利用一个小型多层感知器，输入为 `(x, y, z, 视线方向)`，输出为 `(颜色, 密度)`。通过沿光线路径进行积分来实现渲染。其在图像质量上优于基于网格的新视图合成方法，但渲染速度却慢100至1000倍。尽管在大多数实时应用中已被高斯溅射技术取代，但在研究领域仍占据主导地位。

## 构建它

`code/main.py` 实现了一个简化的二维“高斯溅射”拟合算法：将合成目标图像（即平滑的渐变图）表示为多个二维高斯溅射函数的叠加。通过梯度下降法优化这些高斯函数的位置、颜色以及协方差，以使其尽可能匹配目标图像。该代码展示了两个核心操作：正向渲染（高斯溅射与阿尔法混合）以及基于梯度下降的拟合过程。

### 步骤 1：二维高斯散点图

```python
def gaussian_at(x, y, gaussian):
    px, py = gaussian["pos"]
    sigma = gaussian["sigma"]
    d2 = (x - px) ** 2 + (y - py) ** 2
    return math.exp(-d2 / (2 * sigma * sigma))
```

### 步骤 2：通过累加斑点进行渲染

```python
def render(image_size, gaussians):
    img = [[0.0] * image_size for _ in range(image_size)]
    for g in gaussians:
        for y in range(image_size):
            for x in range(image_size):
                img[y][x] += g["color"] * gaussian_at(x, y, g)
    return img
```

真实的 3D 高斯点涂算法会按深度对高斯函数进行排序，并依次进行阿尔法混合。而我们之前的 2D 简化模型仅执行求和操作。

### 步骤 3：通过梯度下降进行拟合

```python
for step in range(steps):
    pred = render(size, gaussians)
    loss = mse(pred, target)
    gradients = compute_grads(pred, target, gaussians)
    update(gaussians, gradients, lr)
```

## 常见陷阱

- **视图不一致问题。** 若独立生成4个视图，且这些视图在物体结构上存在差异，则3D拟合效果会变得模糊不清。解决方案：采用带有共享注意力的多视图扩散技术。
- **背面幻觉问题。** 单张图像生成3D模型时，必须自行构造出不可见的背面部分，从而导致质量波动极大。
- **高斯斑点激增问题。** 在无约束训练条件下，斑点数量可能增长至1000万个，进而引发过拟合现象。必须采用来自3D-GS原始论文中的密度优化与剪枝策略。
- **拓扑结构问题。** 通过隐式场（如SDF）生成的网格往往存在孔洞或自相交情况。在最终交付前需使用重网格化工具（例如Blender的体素重网格化功能）进行处理。
- **训练数据的许可问题。** Objaverse平台上的数据拥有不同的许可协议；不同模型的商业使用权限也各不相同。

3. **困难。** 使用 gsplat 或 Nerfstudio，根据50张照片重建真实物体。需报告重建耗时以及针对保留样本的最终结构相似性指数值。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| 3D 高斯溅射 | “3DGS” | 将场景表示为三维高斯点云；通过可微分的阿尔法混合方式进行渲染。 |
| NeRF | “神经辐射场” | 一种多层感知机，可在三维空间中的任意点输出颜色与密度值；通过光线积分进行渲染。 |
| 三平面模型 | “三个二维平面” | 将三维空间分解为三个相互垂直的二维特征网格；相比体积渲染方法成本更低。 |
| SDS | “得分蒸馏采样” | 利用二维扩散模型的得分作为伪梯度来训练三维模型。 |
| 多视图扩散模型 | “同时处理多个视图” | 一种扩散模型，能够生成一批一致的相机视角图像。 |
| PBR | “基于物理的渲染” | 具有反射率、粗糙度、金属度及法线通道等属性的材料模型。 |
| 密集化处理 | “扩展溅射点” | 3D 高斯溅射训练中的优化策略：在梯度较高的区域对溅射点进行分割或克隆。 |

## 生产备注：3D版本目前尚无共享基板。

与图像（潜在扩散模型 + DiT）和视频（时空 DiT）不同，2026 年的 3D 领域尚未出现单一的主流运行时。技术选型决策树会根据数据表示方式分为以下几支：

- **NeRF / triplane**：推理过程包括光线追踪以及每个样本对应的 MLP 前向传播。渲染一个 512² 的场景需要执行数百万次 MLP 前向传播。需对光线采样进行大规模批处理，并采用 SDPA/xformers 算法。
- **多视图扩散模型 + LRM 重建**：采用两阶段流程。第一阶段（多视图 DiT）与第 07 课中的扩散服务器类似；第二阶段（LRM 变换器）则是对各视图进行一次性前向传播。整体延迟特征为“扩散过程 + 一次性处理”——需根据各阶段的特性选择相应的服务实现方式。
- **SDS / DreamFusion**：侧重于针对特定资产的优化，而非实时推理。这类技术用于构建处理任务，而非处理请求。

对于 2026 年的大多数产品而言，最佳方案是“按需运行多视图扩散模型，异步将结果重建为 3DGS 格式，再通过 3DGS 提供实时查看体验”。这种方式能够将工作负载清晰地划分在 GPU 推理服务器（处理速度快）与离线优化器（处理速度慢）之间。
