# 流匹配与修正流

> 扩散模型需要 20-50 次采样步骤，因为它们是从噪声到数据的路径是弯曲的。流匹配方法（Lipman 等人，2023 年）和修正流方法（Liu 等人，2022 年）则用于训练直线路径。更直的路径意味着更少的步骤，从而实现更快的推理速度。Stable Diffusion 3、Flux.1 和 AudioCraft 2 均在 2024 年转向了流匹配技术。

**类型：** 构建
**语言：** Python
**先修要求：** 第 8 阶段 · 06（DDPM）、第 1 阶段 · 微积分
**耗时：** 约 45 分钟

## 问题所在

DDPM的逆向过程是从`N(0, I)`出发、经过1000步随机游走才能回到数据分布的过程。而DDIM则将其简化为20到50步的确定性步骤。理想情况下，我们希望将步骤数进一步减少至1步。但实现这一目标的障碍在于，用于求解逆向过程的常微分方程具有强刚性，导致路径呈现弯曲状态。

如果能够训练模型，使得从噪声到数据的路径为*直线*，那么仅需从`t=1`到`t=0`执行一次欧拉积分即可。流匹配技术正是直接实现了这一点：它定义了从`x_1 ∼ N(0, I)`到`x_0 ∼ data`的直线插值，并训练向量场`v_θ(x, t)`使其时间导数与该插值相匹配，最终在推理阶段进行积分运算。

修正流方法（Liu 2022）则更进一步：通过一种重流流程迭代地拉直路径，从而生成越来越接近线性形式的常微分方程。经过两次重流迭代后，仅需2步的采样器即可达到与50步DDPM相当的质量。

## 概念概述

![流匹配：噪声与数据之间的直线插值](../assets/flow-matching.svg)

### 线性流程

定义：

```
x_t = t · x_1 + (1 - t) · x_0,   t ∈ [0, 1]
```

其中 `x_0 ~ data` 且 `x_1 ~ N(0, I)`。沿此直线的时间导数是恒定的：

```
dx_t / dt = x_1 - x_0
```

定义一个神经向量场 `v_θ(x_t, t)`，并训练它以匹配该导数：

```
L = E_{x_0, x_1, t} || v_θ(x_t, t) - (x_1 - x_0) ||²
```

这是**条件流匹配**损失函数（Lipman 2023）。其训练过程无需仿真：无需展开常微分方程。只需采样 `(x_0, x_1, t)` 并进行回归即可。

### 采样

在推理阶段，需将学到的向量场沿时间方向*反向*整合：

```
x_{t-Δt} = x_t - Δt · v_θ(x_t, t)
```

从 `x_1 ~ N(0, I)` 开始，通过欧拉步法逐步递推至 `t=0`。

### 修正流（Liu 2022）

直线流虽然可行，但学习到的路径实际上并非笔直——由于多个 `x_0` 可能对应同一个 `x_1`，因此这些路径会呈现弯曲。修正流的重构步骤如下：

1. 使用随机配对方式训练流模型 v_1。
2. 通过从 `x_1` 积分至其对应的终点 `x_0`，采样 N 对 `(x_1, x_0)` 数据。
3. 基于这些配对的样本训练 v_2。由于这些配对已实现“常微分方程级匹配”，它们之间的直线插值将更加平坦。
4. 重复上述步骤。

在实际应用中，经过 2 次重构迭代后即可获得近似线性关系，从而支持 2-4 步的推理过程。SDXL-Turbo、SD3-Turbo 和 LCM 均属于基于流匹配技术精简而来的模型。

### 为何它在 2024 年的图像类别中获奖

三个原因：

1. **无需仿真的训练**——训练过程中不会展开常微分方程，实现极为简单。
2. **更优的损失函数特性**——直线路径的信噪比保持稳定，而 DDPM 的 ε 损失在调度边缘区域的信噪比表现较差。
3. **更快的推理速度**——仅需 4-8 步即可达到 SDXL-Turbo 的质量；采用一致性蒸馏技术时仅需 1 步。

## 流匹配与DDPM——二者之间的确切关联

使用高斯条件路径的流匹配实际上是一种*具有特定噪声调度*的扩散过程。选择 `x_t = α(t) x_0 + σ(t) x_1` 这一调度后，流匹配即可还原为经过斯特拉托诺维奇重构的扩散模型，其表达式为 `v = α'·x_0 - σ'·x_1`。对于高斯路径而言，这两种形式在代数上是等价的。

流匹配带来的优势包括：目标变量的*清晰性*（仅为一个简单的速度值）、更简洁的损失函数，以及允许使用非高斯插值函数的实验空间。

## 构建它

`code/main.py` 实现了基于双模高斯混合模型的一维流匹配算法。向量场 `v_θ(x, t)` 是一个使用直线目标函数训练得到的小型多层感知器。在推理阶段，分别进行1步、2步、4步和20步的欧拉积分，并对比不同积分步数下的样本质量。

### 步骤 1：训练损失

```python

    x1 = rng.gauss(0, 1)
    t = rng.random()
    x_t = t * x1 + (1 - t) * x0
    target = x1 - x0
    pred = net_forward(x_t, t)
```

### 步骤 2：多步推理

```python
def sample(net, num_steps):
    x = rng.gauss(0, 1)
    for i in range(num_steps):
        t = 1.0 - i / num_steps
        dt = 1.0 / num_steps
        x -= dt * net_forward(x, t)
    return x
```

## 常见陷阱

- **时间参数化。** 流匹配采用 `t ∈ [0, 1]` 的设定，其中 `t=0` 对应数据部分，`t=1` 对应噪声部分。DDPM 则使用 `t ∈ [0, T]`，`t=0` 对应数据部分，`t=T` 对应噪声部分。二者方向相同，但时间尺度不同。许多论文在此处经常出错。
- **调度选择。** 矫正流所采用的直线型调度是流匹配的“标准”方案，但为了获得更佳的时间尺度覆盖范围，也可以使用余弦函数或对数正态分布的 t 采样方式（SD3 即采用此方法）。
- **重流成本。** 为重流生成配对数据集需要针对每个样本进行一次完整的推理过程。只有当确实需要 1-2 步的推理时才应进行重流操作。
- **无分类器引导机制依然适用。** 只需在线性组合中将 ε 替换为 v 即可：`v_cfg = (1+w) v_cond - w v_uncond`。

## 练习题

1. **简单。** 运行 `code/main.py`，并对比一步预测、二十步预测的均方误差与真实数据分布的情况。
2. **中等难度。** 将均匀采样 `t` 更改为对数正态采样（使采样集中在中间值附近）。模型质量会有提升吗？
3. **高难度。** 实现一次重流迭代：通过第一个模型进行积分生成配对数据 `(x_0, x_1)`，基于这些配对数据训练第二个模型，然后对比一步预测的样本质量。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| 流场匹配 | “直线扩散” | 训练 `v_θ(x, t)`，使其沿着插值曲线与 `x_1 - x_0` 相匹配。 |
| 矫正流场 | “重流” | 一种用于修正已学习流场的迭代算法。 |
| 速度场 | “v_θ” | 模型的输出——表示 `x_t` 的移动方向。 |
| 直线插值曲线 | “路径” | 表达式为 `x_t = (1-t)·x_0 + t·x_1`；其目标导数非常简单。 |
| 欧拉采样器 | “一阶常微分方程求解器” | 最简单的积分器；在路径为直线时表现良好。 |
| 对数正态分布的 t 值 | “SD3 采样” | 将 `t` 的采样集中在梯度最强的中间值附近。 |
| 一致性蒸馏 | “单步采样器” | 训练一个模型，使其能够直接将任意 `x_t` 映射为 `x_0`。 |
| 带速度的条件生成函数 | “v-CFG” | 表达式为 `v_cfg = (1+w) v_cond - w v_uncond`；原理相同，仅变量不同。 |

## 生产说明：Flux.1-schnell 是速度最快的流匹配版本

流匹配技术在生产环境中的佼佼者是 Flux.1-schnell —— 这是一种经过流匹配处理的 DiT 模型，其在保持 Flux 开发版质量的同时将推理步骤压缩至 1 到 4 步。Niels 发布的《在 8GB 硬件上运行 Flux》笔记提供了标准的部署方案：先使用 T5 和 CLIP 进行编码，再通过量化后的 MMDiT 执行去噪处理（schnell 版本需 4 步，而开发版则需要 50 步），最后由 VAE 进行解码。相关成本对比如下：

| 变体 | 推理步骤 | 在 L4 硬件、1024² 分辨率下的延迟 | 总 FLOPs（相对值） |
|---------|-------|------------------------|------------------------|
| Flux.1-dev（原始版） | 50 | 约 15 秒 | 1.0× |
| Flux.1-schnell | 4 | 约 1.2 秒 | 0.08×（速度快 12 倍） |
| SDXL-base | 30 | 约 4 秒 | 0.25× |
| SDXL-Lightning 2-step | 2 | 约 0.3 秒 | 0.03× |

行业通用准则为：**“流匹配基础模型 + 蒸馏技术 = 2026 年快速文本生成图像领域的标准方案”**。所有主流供应商均提供此类组合：SD3-Turbo（SD3 + 流匹配 + 蒸馏技术）、Flux-schnell（Flux 开发版 + 矫正流处理技术）以及 CogView-4-Flash。仅有旧版检查点仍使用纯扩散基础模型。
