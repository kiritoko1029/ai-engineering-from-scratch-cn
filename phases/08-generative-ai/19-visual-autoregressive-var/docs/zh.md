# 视觉自回归建模（VAR）：更高阶的预测技术

> 扩散模型通过逐次迭代的方式在时间维度上采样（即去噪步骤）。而 VAR 则在尺度维度上逐次迭代——它先预测 1x1 的 token，接着是 2x2，再是 4x4，直至达到最终分辨率，且每个尺度的预测都会以之前的结果作为条件。2024 年的论文表明，在图像生成方面 VAR 符合 GPT 风格的尺度规律，并且在相同的计算资源下性能优于 DiT。本课将讲解其核心机制。

**类型：** 构建
**语言：** Python（配合 PyTorch）
**先修知识：** 第 7 阶段第 03 课（多头注意力），第 8 阶段第 06 课（DDPM）
**时长：** 约 90 分钟

## 问题所在

自回归生成方式之所以在语言建模领域占据主导地位，是因为其性能提升具有可预测性：计算资源越多、参数数量越多，模型的困惑度越低，生成的输出质量也越高。在2024年之前，图像生成领域主要有两种自回归尝试：PixelRNN/PixelCNN（逐像素处理）以及DALL-E 1 / Parti / MuseGAN（基于VQ-VAE编码的逐令牌处理）。

这两种方法都存在生成顺序问题。尽管像素和令牌都是以二维网格的形式排列，但自回归模型却必须按照一维的扫描顺序来处理它们。位于角落处的早期像素根本无法预知最终生成的图像会是什么样子。其生成质量的增长速度甚至慢于基于文本的GPT模型，在相同的计算资源下也永远无法达到扩散模型的质量水平。

VAR通过改变生成对象来解决这一生成顺序问题。它不再逐个预测空间中的图像令牌，而是逐步以越来越高的分辨率来预测整幅图像。具体步骤如下：第一步，预测一个1x1大小的令牌（即整个图像的“概要”）；第二步，预测2x2大小的令牌网格（对应更粗略的特征）；第三步，预测4x4大小的令牌网格；第K步，则预测最终尺寸为(H/8)x(W/8)的令牌网格。

在每个分辨率层级上，模型既会考虑所有较低层级的信息（按照“层级顺序”实现因果关联），也会在同一层级内并行处理各部分信息。这样一来，生成顺序问题便不复存在——在单次Transformer计算过程中即可生成k层级对应的完整图像。

## 概念概述

### VQ-VAE多尺度分词器

VAR 需要一个**多尺度离散分词器**。对于图像 x，它会生成一系列分辨率逐渐提高的令牌网格：

```
x -> encoder -> latent f
f -> tokenize at 1x1: token grid z_1 of shape (1, 1)
f -> tokenize at 2x2: token grid z_2 of shape (2, 2)
...
f -> tokenize at (H/p)x(W/p): token grid z_K of shape (H/p, W/p)
```

每个 z_k 都使用相同的码本（典型大小为 4096–16384）。不同尺度下的分词过程并非相互独立——该模型经过训练，使得各尺度下残差之和能够重构出 f：

```
f ≈ upsample(embed(z_1), target_size) + ... + upsample(embed(z_K), target_size)
```

这是**残差VQ**的变体。尺度k用于捕捉尺度1到k-1所遗漏的信息。解码器会取所有尺度嵌入向量的和，进而生成图像。

多尺度VQ分词器与VQGAN类似，仅训练一次后即被冻结。所有的生成工作均由其上层的自回归模型来完成。

### 大规模预测系统

该生成模型是一种Transformer，它能够查看所有先前层级中的标记，并预测下一层级的标记。

输入序列结构：
```
[START, z_1 tokens, z_2 tokens, z_3 tokens, ..., z_K tokens]
```

位置嵌入同时编码了尺度索引以及该尺度内的空间位置。注意力机制遵循尺度顺序的因果关系：位于第 k 个尺度的、位置为 (i, j) 的标记，可以关注第 1 到 k 个尺度中的所有标记，以及同一尺度内按某种内部顺序排列在它之前的标记（VAR 使用固定的位置注意力机制，不存在尺度内的因果关系——同一尺度内的所有位置都是并行预测的）。

训练损失：对于每个尺度 k，根据所有前序尺度的标记来预测 z_k 标记。采用离散 VQ 编码的交叉熵损失函数。其结构与 GPT 相同，不同之处在于“序列”现在是以尺度为结构的。

### 生成

推理时：
```
generate z_1 = sample from p(z_1)                    # 1 token
generate z_2 = sample from p(z_2 | z_1)              # 4 tokens in parallel
generate z_3 = sample from p(z_3 | z_1, z_2)         # 16 tokens in parallel
...
decode: f = sum of embed-and-upsample scales 1..K
image = VAE_decoder(f)
```

当 K = 10 时，生成过程相当于执行 10 次 Transformer 前向传播。每次传播会并行生成整个尺度级别的输出——在单个尺度内不会进行逐个标记的自动回归处理。对于 256x256 的图像而言，这一流程大约需要 10 次传播，而 DiT 则需要 28 至 50 次。

### 为何“Next-Scale”能胜过“Next-Token”

三大结构优势：  
1. **从粗到细的对齐方式符合自然图像的统计特性。** 人类的视觉感知与图像数据集均表现出与尺度相关的规律性：低频结构稳定且可预测；高频细节则取决于低频内容。下一层级的预测正是利用了这一特点。  
2. **同一尺度内的并行生成。** 不同于 GPT 风格的逐词自回归，VAR 能够一步生成某一尺度下的所有标记。其有效生成长度呈对数级而非线性增长。  
3. **无生成顺序偏差。** 属于第 k 层级的标记能够看到第 k-1 层级的全部内容；不存在迫使早期标记在后期上下文尚未出现时就确定的“左侧”或“上方”偏差。

### 标度律

Tian等人证明，对于ImageNet数据集的FID指标，VAR模型遵循幂律缩放曲线——这与GPT模型在困惑度指标上的表现如出一辙。参数或计算资源增加一倍时，误差可稳定地降低一半。这是首个像语言模型那样展现出如此清晰缩放行为的图像生成模型。由此带来的结果是，基于VAR模型的预测可以通过计算得出，而无需依赖针对特定架构的经验性估算。

### 与扩散算法的关系

VAR模型与扩散模型在数据压缩的原理上具有共通之处：二者均将生成问题分解为一系列更易于处理的子问题。

- 扩散模型：逐步添加噪声，学习如何撤销一步操作。
- VAR模型：逐步提升分辨率，学习如何预测下一个尺度。

它们是从不同维度解决该问题的方法。但两者都能得到可处理的条件分布。从实验结果来看，VAR模型在推理速度上更快（需要更少的迭代次数，且同一尺度内的所有计算均可并行进行），其在基于类别条件的ImageNet任务上的表现可与DiT模型相媲美甚至更优。基于文本条件的VAR模型（如VARclip、HART）是目前的研究热点方向。

## 构建它

在 `code/main.py` 中，你需要完成以下步骤：
1. 基于合成的“图像”数据（2D 高斯环）构建一个小型**多尺度 VQ 分词器**。
2. 训练一个**VAR 风格的变换器**，用于对下一个尺度上的分词符进行预测。
3. 通过调用该变换器 4 次（对应 4 个尺度）并进行解码来生成样本。
4. 验证按尺度顺序训练是否能使同一尺度内的生成过程实现并行处理。

这是一个简化版的实现。其目的是展示基于尺度结构的注意力掩码以及同一尺度内并行生成的机制确实能够正常工作。

## 练习题

1. **尺度数量消融实验。** 使用 4、6、8、10 个尺度训练 VAR 模型。测量重建质量与自回归迭代次数的关系。尺度越多，残差越精细，重建质量越高，但所需的迭代次数也会增加。

2. **码本大小。** 使用 512、4096、16384 不同大小的码本训练分词器。更大的码本能够提升重建质量，但会增加预测难度。需要找到性能最佳的码本大小。

3. **尺度内部并行性检查。** 对已训练好的 VAR 模型，显式地分析其注意力模式。在第 k 个尺度内，模型是否关注跨尺度的位置而非同一尺度内的位置？以此验证掩码机制的正确实现。

4. **VAR 与 DiT 的扩展性对比。** 针对相同的 ImageNet 类条件任务，在参数量保持一致的情况下（例如 33M、130M、458M）分别训练 VAR 和 DiT 模型。绘制 FID 值随计算资源消耗的变化曲线。在各个参数规模下，VAR 的性能均应优于 DiT——并复现该论文在小尺度下的实验结果。

5. **文本条件化处理。** 通过 adaLN 机制，将文本嵌入（CLIP 池化后的向量）作为额外的条件输入引入 VAR 模型中，即实现 HART 方法。在采用文本对齐采样方式后，FID 值能提升多少？

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| VAR | “视觉自回归” | 通过在 VQ 令牌网格的金字塔结构上逐层进行预测来生成图像 |
| 逐级预测 | “先预测粗略层级，再预测精细层级” | 模型在所有先前层级作为条件的前提下，按逐渐提高的分辨率层级预测令牌 |
| 多尺度 VQ 分词器 | “残差 VQ” | 一种 VQ-VAE，可生成 K 个分辨率逐级提升的令牌网格，解码器会将所有层级的嵌入相加 |
| 第 k 层级 | “金字塔的第 k 级” | 共有 K 个分辨率层级之一，k=1 时为 1x1，k=K 时为 (H/p)x(W/p) |
| 同一层级内并行处理 | “每个层级仅进行一次前向传播” | 第 k 层级的所有令牌都在一次 Transformer 前向传播中同时预测，而非采用自回归方式 |
| 跨层级因果关联 | “按层级顺序的注意力机制” | 第 k 层级的令牌可以关注 1..k 所有层级，但无法关注 k+1..K 的层级 |
| 残差 VQ | “加性分词方式” | 各层级的令牌用于编码较低层级留下的残差信息；解码器会将所有层级的嵌入相加 |
| VAR 缩放定律 | “图像 GPT 的缩放规律” | FID 值与计算量之间存在可预测的幂律关系，类似于语言模型中的困惑度 |
| HART | “混合式 VAR + 文本处理” | 一种基于文本条件的 VAR 变体，结合了 MaskGIT 风格的迭代解码方式与 VAR 的层级结构 |
| 层级位置嵌入 | “(层级, 行号, 列号) 三元组” | 位置编码同时包含层级索引以及该层级内的空间坐标信息 |
