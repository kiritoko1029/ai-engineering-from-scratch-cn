# 扩散模型——从零实现 DDPM

> Ho、Jain 和 Abbeel（2020）为该领域提供了一种令人难以摆脱的实现方案：通过上千次微小的步骤向数据中注入噪声，训练一个神经网络来预测这些噪声，在推理阶段则反向执行该过程。如今，所有主流的图像、视频、3D 以及音乐处理模型都在使用这一循环，有时还会在此基础上加入流匹配或一致性优化技术。

**类型：** 构建
**语言：** Python
**先修知识：** 第3阶段·02（反向传播）、第8阶段·02（变分自编码器）
**耗时：** 约75分钟

## 问题所在

你需要一个用于 `p_data(x)` 的采样器。GANs 所扮演的极小极大博弈往往会导致模型发散，而 VAEs 则会通过高斯解码器生成模糊的样本。你真正需要的是这样一个训练目标：(a) 采用单一且稳定的损失函数（不存在鞍点，也不涉及极小极大问题）；(b) 能为 `log p(x)` 提供下界，从而获得似然值；(c) 生成的样本能达到当前最先进水平的质量。

Sohl-Dickstein 等人（2015年）从理论上给出了解决方案：定义一个逐步加入高斯噪声的马尔可夫链 `q(x_t | x_{t-1})`，并训练反向链 `p_θ(x_{t-1} | x_t)` 以去除噪声。Ho、Jain 和 Abbeel（2020年）证明该损失函数可以简化为仅预测噪声的形式，并进一步优化了相关数学推导。2020年时这还只是一种有趣的理论探索，2021年它已能生成最先进的样本，2022年则演变成了 Stable Diffusion，而到了2026年，它已成为该领域的核心基础技术。

## 概念概述

![DDPM：正向加噪，反向去噪](../assets/ddpm.svg)

**正向过程 `q`。** 在 `T` 个小的时间步中逐步添加高斯噪声。其解析解——也是该数学模型易于处理的原因——在于累积后的步骤同样服从高斯分布：

```
q(x_t | x_0) = N( sqrt(α̅_t) · x_0,  (1 - α̅_t) · I )
```

其中，对于 `β_t` 的调度，有 `α̅_t = ∏_{s=1..t} (1 - β_s)`。在 T=1000 步的范围内，将 `β_t` 从 1e-4 线性变化到 0.02，且 `x_T` 近似服从 `N(0, I)` 分布。

**反向过程 `p_θ`。** 训练一个神经网络 `ε_θ(x_t, t)`，用于预测所添加的噪声。给定 `x_t` 后，通过以下方式进行去噪：

```
x_{t-1} = (1 / sqrt(α_t)) · ( x_t - (β_t / sqrt(1 - α̅_t)) · ε_θ(x_t, t) )  +  σ_t · z
```

其中，`σ_t` 可以是 `sqrt(β_t)`，也可以是经过学习的方差。该表达式虽然形式复杂，但实际上只是代数运算——根据后验概率 `q(x_{t-1} | x_t, x_0)` 求解 `x_{t-1}`，并将 `x_0` 替换为其基于噪声预测的估计值。

**训练损失。**

```
L_simple = E_{x_0, t, ε} [ || ε - ε_θ( sqrt(α̅_t) · x_0 + sqrt(1 - α̅_t) · ε,  t ) ||² ]
```

从数据中采样 `x_0`，随机选取一个 `t`，令 `ε ~ N(0, I)`，通过解析公式一次性计算出带噪声的 `x_t`，然后对该噪声进行回归分析。仅需一个损失函数，无需极小极大优化、KL散度或重参数化技巧。

**采样过程。** 令 `x_T ~ N(0, I)`。从 `t = T` 逐步反向迭代至 `1`。即完成采样。

## 其工作原理

三种直观认知：

1. **去噪容易，生成困难。** 在 `t=T` 时，数据纯粹是噪声——神经网络只需解决一个极其简单的问题。在 `t=0` 时，网络仅需清理少量像素。在中间时刻 `t`，问题虽然变得复杂，但来自不同噪声水平的众多梯度会同时作用于相同的权重上。

2. **伪装形式的得分匹配。** Vincent（2011）证明了预测噪声等价于估计 `∇_x log q(x_t | x_0)`，即*得分*。反向随机微分方程利用这一得分来沿着密度梯度前进——这是一种朝向高概率区域的引导式随机游走。

3. **ELBO可简化为简单的MSE。** 完整的变分下界在每个时间步都包含一个KL项。通过DDPM的参数化方式，这些KL项会简化为带有特定系数的噪声预测MSE；Ho去掉了这些系数（称之为“简单”损失），结果模型的质量得到了提升。

## 构建它

`code/main.py` 实现了一个一维 DDPM 模型。数据为双模混合分布。“网络”是一个小型多层感知机，输入为 `(x_t, t)`，输出预测的噪声值。训练过程采用单行损失函数。采样则通过反向传播算法进行迭代。

### 步骤 1：正向调度（封闭形式解）

```python
betas = [1e-4 + (0.02 - 1e-4) * t / (T - 1) for t in range(T)]
alphas = [1 - b for b in betas]
alpha_bars = []
cum = 1.0
for a in alphas:
    cum *= a
    alpha_bars.append(cum)
```

### 步骤 2：一次性采样 `x_t`

```python
def forward_sample(x0, t, alpha_bars, rng):
    a_bar = alpha_bars[t]
    eps = rng.gauss(0, 1)
    x_t = math.sqrt(a_bar) * x0 + math.sqrt(1 - a_bar) * eps
    return x_t, eps
```

### 步骤 3：一个训练步

```python
def train_step(x0, model, alpha_bars, rng):
    t = rng.randrange(T)
    x_t, eps = forward_sample(x0, t, alpha_bars, rng)
    eps_hat = model_forward(model, x_t, t)
    loss = (eps - eps_hat) ** 2
    return loss, gradient_step(model, ...)
```

### 步骤 4：逆向采样

```python
def sample(model, alpha_bars, T, rng):
    x = rng.gauss(0, 1)
    for t in range(T - 1, -1, -1):
        eps_hat = model_forward(model, x, t)
        beta_t = 1 - alphas[t]
        x = (x - beta_t / math.sqrt(1 - alpha_bars[t]) * eps_hat) / math.sqrt(alphas[t])
        if t > 0:
            x += math.sqrt(beta_t) * rng.gauss(0, 1)
    return x
```

对于一个具有40个时间步长、使用24单元多层感知器的1维问题，该模型大约在200个训练周期内即可学习到双模混合分布。

## 时间条件控制

网络需要知道当前处于哪个时间步进行去噪。有两种标准方案：

- **正弦嵌入法。** 类似于 Transformer 的位置编码。其公式为 `embed(t) = [sin(t/ω_0), cos(t/ω_0), sin(t/ω_1), ...]`。将该嵌入向量通过多层感知机处理后，再广播到整个网络中。
- **FiLM / 组归一化条件控制法。** 在每个模块处将嵌入向量投影到各通道的缩放因子和偏置量上。

我们示例代码中使用的是正弦嵌入法并随后进行向量拼接；而实际生产环境中的 U-Nets 则采用 FiLM 方法。

## 常见陷阱

- **调度至关重要。** 线性 `β` 是 DDPM 的默认设置，但在相同的计算资源下，余弦调度（Nichol & Dhariwal, 2021）能获得更低的 FID 值。若图像质量出现停滞，则需更换调度策略。
- **时间步嵌入较为脆弱。** 将原始的浮点数 `t` 直接传递在 1 维简单场景中可行，但在处理图像时则不可行；务必使用合适的嵌入方式。
- **V 预测与 ε 预测。** 在极小的或极大的时间步范围内，`ε` 的信噪比较差。V 预测（`v = α·ε - σ·x`）更为稳定；SDXL、SD3 和 Flux 均采用该预测方式。
- **无分类器引导。** 在推理阶段，需同时计算条件 `ε` 和无条件 `ε`，随后通过公式 `ε_cfg = (1 + w) · ε_cond - w · ε_uncond` 计算最终值，其中 `w ≈ 3-7`。相关内容见第 08 课。
- **1000 步属于过量计算。** 实际生产环境中通常使用 DDIM（20-50 步）、DPM-Solver（10-20 步）或蒸馏技术（1-4 步）。详情请参阅第 12 课。

## 练习题

1. **简单。** 在 `code/main.py` 中将参数 T 从 40 更改为 10。样本质量（输出结果的可视化直方图）会如何下降？在何种 T 值下，该双模结构会崩溃？
2. **中等难度。** 将预测方式从 ε-预测切换为 v-预测，并重新推导反向步骤。比较最终得到的样本质量。
3. **困难。** 添加无分类器引导机制。以类别标签 `c ∈ {0, 1}` 作为条件，在训练过程中有 10% 的概率省略该标签，而在采样时使用公式 `ε = (1+w)·ε_cond - w·ε_uncond` 进行计算。分别在 `w = 0, 1, 3, 7` 的情况下测量条件模式命中率。

## 关键术语

| 术语 | 通俗说法 | 实际含义 |
|------|----------|----------|
| 正向过程 | “添加噪声” | 用于破坏数据的固定马尔可夫链 `q(x_t \| x_{t-1})`。 |
| 反向过程 | “去噪” | 用于重建数据的训练得到的链 `p_θ(x_{t-1} \| x_t)`。 |
| β调度 | “噪声阶梯” | 每一步的方差；可采用线性、余弦或S形函数形式。 |
| α̅ | “Alpha bar” | 累积乘积 `∏(1 - β)`；可用于从 `x_0` 推导出 `x_t` 的显式表达式。 |
| 简单损失函数 | “基于噪声的MSE” | `\|\|ε - ε_θ(x_t, t)\|\|²`；所有变分推导最终都会简化为此形式。 |
| ε预测 | “预测噪声” | 输出即为所添加的噪声；即标准的DDPM方法。 |
| V预测 | “预测速度” | 输出为 `α·ε - σ·x`；能在不同时间步间提供更好的条件作用。 |
| DDPM | “那篇论文” | Ho等人2020年的研究；采用线性β调度，1000步，配合U-Net结构。 |
| DDIM | “确定性采样器” | 非马尔可夫采样器，需要20-50步，但训练目标与DDPM相同。 |
| 无分类器引导 | “CFG” | 通过混合条件噪声预测和无条件噪声预测来增强条件作用效果。 |

## 生产注意事项：扩散推理本质上是一个步数计数问题。

DDPM 论文采用了 T=1000 次的逆向采样步骤。但在实际生产环境中无人会采用如此高的步数。所有真实的推理框架都会选择以下三种策略之一——每种策略都能清晰地对应到“延迟源自何处”这一生产环境中的核心问题：

1. **使用更快的采样器，保持模型不变**。例如 DDIM（20-50 步）、DPM-Solver++（10-20 步）、UniPC（8-16 步）。这些方法可直接替代原有的逆向循环，且无需修改已训练好的 `ε_θ` 权重，能够将延迟降低 20-50 倍。

2. **蒸馏技术**。通过训练一个“学生模型”使其在更少的步骤内达到与“教师模型”相同的效果：包括渐进式蒸馏（从 2 步降至 1 步）、一致性模型（从任意步数降至 1-4 步）、LCM、SDXL-Turbo、SD3-Turbo 等。此类方法可进一步将延迟降低 5-10 倍，但需要重新进行训练。

3. **缓存与编译优化**。例如使用 `torch.compile(unet, mode="reduce-overhead")`、TensorRT-LLM 的扩散模型后端、`xformers`/SDPA 注意力机制以及 bf16 格式的权重存储。这些方法可将每步的延迟降低约 2 倍，通常会与策略（1）和（2）结合使用。

对于生产环境中的扩散模型服务器而言，其性能权衡逻辑与现有关于大语言模型的研究结论一致：延迟为 `num_steps × step_cost + VAE_decode`，吞吐量为 `batch_size × (num_steps × step_cost)^-1`。由于单次生成仅需一步时间，TTFT 值很小；而从用户视角来看，图像生成是“一次性”完成的，因此其等效的 TPOT 值即为整个响应时间。
