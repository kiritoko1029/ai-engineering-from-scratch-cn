# GANs — 生成器与判别器

> Goodfellow 在 2014 年的巧妙之处在于完全省去了密度计算步骤。该方法使用两个网络：一个用于生成假样本，另一个用于识别这些假样本。这两个网络会不断相互“斗争”，直到生成的假样本与真实样本无法区分为止。这一方法本不应有效，实际上也常常失效；但即便成功时，其生成的样本在针对特定狭窄领域的应用中仍属于目前文献中最优质的。

**类型：** 构建
**语言：** Python
**先修知识：** 第 3 阶段 · 02（反向传播）、第 3 阶段 · 08（优化器）、第 8 阶段 · 02（VAE）
**耗时：** 约 75 分钟

## 问题所在

VAE 生成模糊的样本，是因为其 MSE 解码器损失函数对于图像的*均值*而言是贝叶斯最优的——而许多合理数字的均值往往是一个模糊不清的数字。你需要的是一种能够奖励*合理性*而非与某个特定目标在像素级上相似度的损失函数。目前并不存在合理的合理性度量公式，必须通过学习来获得。

Goodfellow 的思路是：训练一个分类器 `D(x)` 以区分真实图像和伪造图像；同时训练生成器 `G(z)` 来欺骗 `D`。`G` 所面临的损失信号就是 `D` 当前认为能让人觉得某物是真实的那个标准。随着 `G` 的性能提升，这一标准会不断变化，如同追逐一个移动的目标。如果两个网络都能收敛，那么 `G` 就能在无需显式计算 `log p(x)` 的情况下学会数据分布。

这就是对抗性训练。其数学本质是一个极小极大博弈：

```
min_G max_D  E_real[log D(x)] + E_fake[log(1 - D(G(z)))]
```

到2026年，GAN已不再是当前最先进的生成模型（扩散模型与流匹配技术已取代其地位）。不过，StyleGAN 2/3依然是迄今为止性能最为出色的面部建模工具。在扩散模型的训练过程中，GAN鉴别器被用作*感知损失函数*，而对抗性训练则为快速的单步蒸馏技术（如SDXL-Turbo、SD3-Turbo、LCM）提供了支撑，从而使实时扩散模型成为可能。

## 概念概述

![GAN训练：极小极大博弈中的生成器与判别器](../assets/gan.svg)

**生成器 `G(z)`。** 将噪声向量 `z ~ N(0, I)` 映射为样本 `x̂`。通常采用解码器结构的网络（全连接层或转置卷积层）。

**判别器 `D(x)`。** 将样本映射为一个标量概率值（或得分）。真实样本对应 1，伪造样本对应 0。

**损失函数。** 通过交替更新两种模型来实现优化：

- **训练 `D`：** `loss_D = -[ log D(x) + log(1 - D(G(z))) ]`。基于真实样本为 1、伪造样本为 0 的二元交叉熵损失。
- **训练 `G`：** `loss_G = -log D(G(z))`。这是 Goodfellow 所采用的*非饱和型*形式（原始的 `log(1 - D(G(z)))` 在 `D` 非常确定时会达到饱和状态，导致梯度消失）。

**训练循环。** 先执行一次 `D` 的更新，再执行一次 `G` 的更新，如此循环往复。

**其生效原理。** 若生成器 `G` 能完美拟合数据分布 `p_data`，则判别器 `D` 的表现将无法优于随机水平，因此会在所有样本上输出 0.5；此时生成器 `G` 也无法获得任何梯度更新，从而达到平衡状态。

**其失效原因。** 模式崩溃（生成器 `G` 找到一种判别器 `D` 无法区分的模式并持续生成该模式）、梯度消失（判别器 `D` 学习速度过快导致 `log D` 出现饱和现象）以及训练不稳定性（由学习率、批量大小等因素引起）。

## 让GAN得以运行的变体方案

| 年份 | 创新成果 | 解决方案 |
|------|----------|---------|
| 2015 | DCGAN | 引入卷积/反卷积层、批量归一化以及LeakyReLU函数，实现了首个稳定的GAN架构。 |
| 2017 | WGAN, WGAN-GP | 用Wasserstein距离与梯度惩罚取代了BCE损失函数，解决了梯度消失问题。 |
| 2017 | 频谱归一化 | 为判别器设置了Lipschitz上界，该技术至今仍被用于2026年的判别器设计中。 |
| 2018 | 逐步式GAN | 先训练低分辨率图像，再逐层增加分辨率，首次实现了百万像素级别的生成效果。 |
| 2019 | StyleGAN / StyleGAN2 | 引入映射网络与自适应实例归一化技术，成为固定领域照片级真实度生成的顶尖方案。 |
| 2021 | StyleGAN3 | 不会出现别名问题且具有平移不变性，截至2026年仍是人脸生成领域的黄金标准。 |
| 2022 | StyleGAN-XL | 支持条件生成、具备类别感知能力，并且模型规模更大。 |
| 2024 | R3GAN | 通过更强的正则化机制进行优化，无需特殊技巧即可在1024²分辨率下运行。 |

## 构建它

`code/main.py` 在一维数据上训练一个小型生成对抗网络（GAN），该数据由两个高斯分布的混合构成。生成器和判别器均为单隐藏层的多层感知机（MLP）。我们手动实现前向传播、反向传播以及极小极大迭代过程，旨在直观观察两种典型的故障模式：模式崩溃与梯度消失现象的发生过程。

### 步骤 1：非饱和损失函数

标准的 Goodfellow 损失函数 `log(1 - D(G(z)))` 在 D 以高置信度将 G 生成的假样本判定为假样本时趋近于 0。此时 G 的梯度几乎为零——G 无法得到改进。而非饱和形式的损失函数 `-log D(G(z))` 则呈现出相反的渐近行为：当 D 具有高置信度时该值会急剧增大，从而为 G 提供强烈的优化信号。

```python
def g_loss(d_fake):
    # maximize log D(G(z))  <=>  minimize -log D(G(z))
    return -sum(math.log(max(p, 1e-8)) for p in d_fake) / len(d_fake)
```

### 步骤 2：每个生成器步骤对应一个判别器步骤

```python
for step in range(steps):
    # train D
    real_batch = sample_real(batch_size)
    fake_batch = [G(z) for z in sample_noise(batch_size)]
    update_D(real_batch, fake_batch)

    # train G
    fake_batch = [G(z) for z in sample_noise(batch_size)]  # fresh fakes
    update_G(fake_batch)
```

G 版本需要全新的假数据，否则渐变效果会失效。

### 步骤 3：注意模式坍缩现象

```python
if step % 200 == 0:
    samples = [G(z) for z in sample_noise(500)]
    mode_a = sum(1 for s in samples if s < 0)
    mode_b = 500 - mode_a
    if min(mode_a, mode_b) < 50:
        print("  [!] mode collapse: one mode is starved")
```

典型的症状是：两种实数模式中的一种不再被生成。判别器会停止对其进行修正，因为它从未被视为虚假数据。

## 常见陷阱

- **判别器过强。** 将 D 的学习率降低 2-5 倍，或添加实例/层噪声。如果 D 的准确率超过 95%，生成器将无法正常工作。
- **生成器记住了某种模式。** 在 D 的输入中添加噪声，使用小批量判别器层，或改用 WGAN-GP 算法。
- **批归一化层的统计信息泄露。** 真实批次与虚假批次流经同一个 BN 层时会导致其统计信息混合。应改用实例归一化或谱归一化。
- **Inception-score 的局限性。** 在样本数量较少的情况下，FID 和 IS 指标容易出现波动。评估时应使用至少 10k 个样本。
- **单次采样并不适用于条件生成任务。** 仍需通过 CFG 缩放、截断技巧以及重采样等方法才能获得可用的输出结果。

## 使用它

2026年版的GAN技术栈：

| 场景 | 推荐方案 |
|-----------|----------|
| 真实感人脸，固定姿态 | StyleGAN3（图像最清晰，模型体积最小） |
| 动漫/风格化人脸 | StyleGAN-XL或Stable Diffusion LoRA |
| 图像到图像的转换 | Pix2Pix/CycleGAN（第8阶段·04单元）或ControlNet（第8阶段·08单元） |
| 快速的单步文本转图像 | 扩散模型的对抗蒸馏技术（SDXL-Turbo、SD3-Turbo） |
| 扩散模型训练中的感知损失处理 | 在图像裁剪片段上使用小型GAN鉴别器 |
| 任何多模态、开放式的任务 | 不推荐使用GAN —— 应选用扩散模型或流匹配技术 |

GAN模型虽然图像质量高，但适用范围较窄。一旦应用场景扩展到照片、任意文本提示或视频等领域，应转为使用扩散模型。对抗机制仍以组件形式存在（如感知损失、蒸馏技术），而非作为独立的生成器使用。

## 练习题

1. **简单。** 使用默认设置运行 `code/main.py`。然后将 `D_LR = 5 * G_LR` 设置后重新运行。G 的损失值需要多快才能收敛为常数？
2. **中等难度。** 用 WGAN 损失函数替换 Goodfellow 的 BCE 损失函数：`loss_D = E[D(fake)] - E[D(real)]`，`loss_G = -E[D(fake)]`，并将 D 的权重限制在 `[-0.01, 0.01]` 范围内。这样的训练是否更加稳定？请比较实际耗时的收敛速度。
3. **高难度。** 将一维示例扩展到二维数据（环状结构上的 8 个高斯分布的混合体）。在步骤 1k、5k 和 10k 处，统计生成器能够捕获这 8 种模式中的多少种。需实现小批量判别功能并重新进行测量。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| 生成器 | “G” | 将噪声转换为样本的网络，`G: z → x̂`。 |
| 判别器 | “D” | 分类器 `D: x → [0, 1]`，用于区分真实与伪造数据。 |
| 极小极大博弈 | “那个游戏” | 联合目标的 `min_G max_D` 最优化问题。 |
| 非饱和损失函数 | “解决方案” | 对生成器使用 `-log D(G(z))`，而非 `log(1 - D(G(z)))`。 |
| 模式崩溃 | “G记住了某一种模式” | 尽管输入数据多样，生成器仍只能产生少量不同的输出。 |
| WGAN | “Wasserstein距离” | 用地球移动距离加上梯度惩罚来替代BCE损失函数；使梯度更平滑。 |
| 谱范数 | “Lipschitz技巧” | 通过限制判别器的权重范数来控制其斜率，从而稳定训练过程。 |
| StyleGAN | “最有效的模型” | 包含映射网络与AdaIN技术的模型；在2026年仍是人脸生成领域的最佳选择。 |

## 生产注意事项：单次推理是 GAN 的持久优势

在开放域生成任务中，GAN 在样本质量方面的优势已不复存在，但在推理成本方面仍占据优势。在面向生产环境推理的文献中，GAN 具有以下特点：

- **无需预填充阶段，也无解码阶段**：仅需一次 `G(z)` 的前向传播即可完成处理，总延迟近似等于该前向传播的时间。
- **不存在 KV 缓存压力**：唯一的状态即为模型权重。批量大小受激活值内存的限制，而非缓存容量。
- **可轻松实现连续批处理**：由于每个请求所需的浮点运算量固定不变，通常在服务器目标负载率下设置静态批次即可达到最佳效果，无需额外的运行时调度器。

正因如此，GAN 蒸馏技术（如 SDXL-Turbo、SD3-Turbo、ADD、LCM）成为 2026 年实现快速文本转图像处理的主流方法：它可将原本需要 20 到 50 步的扩散模型流程简化为 1 到 4 次 GAN 风格的前向传播，同时保留原始扩散模型的分布特性。对抗损失则作为训练时的调节参数，用于将慢速生成器转变为高速生成器。
