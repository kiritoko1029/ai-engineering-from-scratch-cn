# 条件生成对抗网络与 Pix2Pix

> 2014年至2017年间首个重要的突破在于能够控制生成对抗网络（GAN）的输出内容。可以为其附加标签、图像或句子等信息。Pix2Pix实现了基于图像的处理方式，在特定的图像转换任务中，其性能依然优于所有通用的文本转图像模型。

**类型：** 构建
**语言：** Python
**先修知识：** 第8阶段·03（生成对抗网络）、第4阶段·06（U-Net）、第3阶段·07（卷积神经网络）
**耗时：** 约75分钟

## 问题所在

无条件生成对抗网络能够随机采样人脸图像。虽适用于演示，但在实际生产环境中毫无用处。您真正需要的是：*将草图映射为照片*、*将地图映射为航拍图*、*将白昼场景转换为夜晚场景*、*为灰度图像上色*。在所有这些任务中，输入均为图像 `x`，输出 `y` 必须与其具有某种语义上的对应关系。对于每个输入 `x`，往往存在多种可能的输出 `y`。均方误差会将这些可能性压缩成模糊的结果，而对抗损失则不会，因为“看起来真实”这一标准本身具有明确的界定。  

条件生成对抗网络（Mirza & Osindero, 2014）会在生成器 `G` 和判别器 `D` 的输入中加入条件 `c`。Pix2Pix（Isola et al., 2017）对这一技术进行了专门优化：条件为完整的输入图像，生成器采用 U-Net 结构，判别器则使用基于块的分类器（PatchGAN），损失函数由对抗损失与 L1 损失组合而成。即便在 2026 年，由于该模型是在*成对数据*上训练的——即直接拥有所需的精确信号——因此其在特定的图像到图像转换任务中的表现仍优于从零开始构建的文本到图像模型。

## 概念概述

![Pix2Pix：U-Net生成器，PatchGAN鉴别器](../assets/pix2pix.svg)

**条件G。** `G(x, z) → y`。在Pix2Pix中，`z`为G内部的dropout层（无输入噪声——Isola发现显式添加的噪声会被忽略）。

**条件D。** `D(x, y) → [0, 1]`。输入为*条件与输出的对*。这是关键区别：D需要判断`y`是否与`x`一致，而不仅仅是判断`y`看起来是否真实。

**U-Net生成器。** 具有跨瓶颈部分的跳跃连接的编解码结构。对于输入与输出共享低级结构（如边缘、轮廓）的任务至关重要。若没有这些跳跃连接，高频细节将会丢失。

**PatchGAN鉴别器。** D不会输出单一的真实/伪造评分，而是输出一个`N×N`网格，其中每个单元格负责判断约70×70像素的感受野区域。最终对所有单元格的结果进行平均处理。这基于马尔可夫随机场假设：真实性是局部的。该结构训练速度更快、参数更少，且输出更加清晰。

**损失函数。**

```
loss_G = -log D(x, G(x)) + λ · ||y - G(x)||_1
loss_D = -log D(x, y) - log (1 - D(x, G(x)))
```

L1项可稳定训练过程，并将生成器G推向已知的目标值。与L2相比，L1能产生更清晰的边缘效果（计算中位数而非均值）。在Pix2Pix中，默认的`λ`值为100。

## CycleGAN — 无配对数据时的解决方案

Pix2Pix 需要成对的 `(x, y)` 数据。而 CycleGAN（Zhu 等人，2017 年）则放弃了这一要求，但需要引入额外的损失函数——即*循环一致性*损失。该模型包含两个生成器 `G: X → Y` 和 `F: Y → X`，通过训练使 `F(G(x)) ≈ x` 且 `G(F(y)) ≈ y` 成立。这样一来，即便没有成对样本，也能实现将马转换为斑马、或将夏季场景转换为冬季场景的效果。

到了 2026 年，无配对图像到图像的转换主要依靠扩散模型（如 ControlNet、IP-Adapter）来实现，而非 CycleGAN，但“循环一致性”这一理念几乎仍存在于所有关于无配对领域自适应的论文中。

## 构建它

`code/main.py` 实现了一个基于一维数据的简易条件生成对抗网络。其中，条件 `c` 表示类别标签（0 或 1）。该任务的目标是：为给定的类别从条件分布中生成一个样本。

### 步骤 1：将条件追加到 G 和 D 输入中

```python
def G(z, c, params):
    return mlp(concat([z, one_hot(c)]), params)

def D(x, c, params):
    return mlp(concat([x, one_hot(c)]), params)
```

独热编码是最简单的方法。规模较大的模型则会使用学习得到的嵌入向量、FiLM调制机制或交叉注意力机制。

### 步骤 2：训练条件模型

```python
for step in range(steps):
    x, c = sample_real_conditional()
    noise = sample_noise()
    update_D(x_real=x, x_fake=G(noise, c), c=c)
    update_G(noise, c)
```

生成器必须匹配*给定条件下的*真实分布，而非边际分布。

### 步骤 3：验证各类别的输出结果

```python
for c in [0, 1]:
    samples = [G(noise, c) for noise in batch]
    mean_c = mean(samples)
    assert_near(mean_c, real_mean_for_class_c)
```

## 常见陷阱

- **条件被忽略。** G模型学会忽略该条件，而D模型由于条件信号较弱从不对其进行惩罚。解决方案：在更早的层级对D模型施加更强约束（而非仅在后期），并使用投影鉴别器（Miyato & Koyama 2018）。
- **L1权重过低。** G模型会生成看似真实但并不准确的输出。对于Pix2Pix类任务，建议初始λ值设为约100。
- **L1权重过高。** 由于L1本质上仍属于L_p范数，G模型会产生模糊的输出。待训练稳定后逐步降低该权重。
- **D模型中存在真实数据泄露。** 应将`(x, y)`作为D模型的输入进行拼接，而不仅仅是`y`。若不这样做，D模型就无法验证输出的一致性。
- **各类别出现模式坍塌现象。** 每个类别都可能独立发生模式坍塌。需执行基于类别的条件多样性检查。

## 使用它

2026年图像到图像任务现状：

| 任务 | 最佳方案 |
|------|---------------|
| 草图 → 照片，同一领域，配对数据 | Pix2Pix / Pix2PixHD（速度依旧快，图像清晰度依然高） |
| 草图 → 照片，非配对数据 | 结合Scribble条件模型的ControlNet |
| 语义分割 → 照片 | SPADE / GauGAN2或SD + ControlNet-Seg |
| 风格迁移 | 使用IP-Adapter或LoRA的扩散模型；GAN方法已属过时 |
| 深度信息 → 照片 | 在Stable Diffusion上使用ControlNet-Depth |
| 超分辨率处理 | Real-ESRGAN（GAN类型）、ESRGAN-Plus或SD-Upscale（扩散模型） |
| 上色 | ColTran、基于扩散模型的上色工具或Pix2Pix-color |
| 白天 → 夜晚、季节变化、天气转换 | CycleGAN或基于ControlNet的方案 |

当满足以下条件时，Pix2Pix仍是最佳选择：(a) 拥有数千个配对样本；(b) 任务范围明确且可重复执行；(c) 需要快速推理。对于通用的开放领域任务，则扩散模型更具优势。

## 练习题

1. **简单。** 修改 `code/main.py` 文件，添加第三个类。验证 G 是否仍能将每个类的噪声正确映射到对应的模式。
2. **中等难度。** 在一维场景下用感知风格损失函数替换 L1 损失函数（例如，使用一个小型且冻结的 D 网络作为特征提取器）。这是否会改变条件分布的锐度？
3. **高难度。** 为一维场景设计一个 CycleGAN：包含两个分布、两个生成器以及循环损失函数。证明该模型无需配对数据即可学会在两者之间进行映射。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| 条件生成对抗网络 | “带标签的GAN” | G(z, c), D(x, c)。两个网络均能看到条件信息。 |
| Pix2Pix | “图像到图像的GAN” | 结合了U-Net G作为生成器、PatchGAN D作为判别器以及L1损失的双cGAN结构。 |
| U-Net | “带跳跃连接的编解码器” | 对称卷积网络；跳跃连接用于保留高频特征。 |
| PatchGAN | “局部真实度分类器” | 判别器D输出的是每个像素块的得分，而非整体图像的得分。 |
| CycleGAN | “非配对图像转换” | 包含两个生成器以及循环一致性损失函数；无需配对数据。 |
| SPADE | “GauGAN” | 利用语义图对中间激活值进行归一化处理；实现从分割图到图像的转换。 |
| FiLM | “基于特征的线性调制” | 根据条件信息对每个特征进行仿射变换；实现低成本的条件控制。 |

## 生产注意事项：作为延迟敏感型基线的 Pix2Pix 模型

当面对配对数据及特定任务（如草图→渲染、语义地图→照片、白天→夜晚）时，Pix2Pix 的单次推理在延迟方面比扩散模型快一个数量级。实际生产环境中的对比通常如下：

| 路径 | 步骤数 | 单台 L4 设备上 512² 分辨率下的典型延迟 |
|------|--------|----------------------------------------|
| Pix2Pix（U-Net 前向传播） | 1 | 约 30 毫秒 |
| SD-Inpaint 或 SD-Img2Img | 20 | 约 1.2 秒 |
| SDXL-Turbo Img2Img | 1-4 | 约 0.15–0.35 秒 |
| ControlNet + SDXL 基础模型 | 20-30 | 约 3–5 秒 |

在静态批量处理场景下（每次请求的浮点运算量相同），Pix2Pix 在吞吐量方面更具优势；而扩散模型则在图像质量和泛化能力上表现更佳。目前的常见做法是为这类特定任务部署经过精简的 Pix2Pix 风格模型，同时准备一个扩散模型作为处理异常输入的备用方案。
