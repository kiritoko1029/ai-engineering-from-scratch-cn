# 多智能体辩论与协作

> Du 等人（ICML 2024，"Society of Minds"）运行 N 个模型实例，各自独立提出答案，然后在 R 轮中迭代相互批评以收敛。提升了事实性、规则遵循和推理能力。稀疏拓扑在 token 成本上优于全连接。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 第 14 阶段 · 12（工作流模式），第 14 阶段 · 05（Self-Refine 与 CRITIC）
**所需时间：** 约60分钟

## 学习目标

- 解释辩论协议：N 个提议者、R 轮、收敛到共享答案。
- 描述为什么辩论能提升事实性、规则遵循和推理能力。
- 解释稀疏拓扑：并非每个辩手都需要看到所有其他人。
- 实现一个标准库辩论，使用脚本化 LLM，包含全连接和稀疏变体；测量 token 成本与准确率。

## 问题所在

Self-Refine（第 05 课）是一个模型自我批评 — 有群体思维的风险。CRITIC（第 05 课）将批评建立在外部工具之上 — 并非总是可用。辩论引入了第三种模式：多个实例、交叉批评、通过分歧收敛。

## 概念说明

### Society of Minds（Du 等人，ICML 2024）

- N 个模型实例独立对同一问题提出答案。
- 在 R 轮中，每个模型阅读其他人的提议并进行批评。
- 模型根据批评更新答案。
- R 轮后返回收敛的答案。

原始实验使用 N=3、R=2 以控制成本。在困难问题（MMLU、GSM8K、国际象棋走法合法性、传记生成）上，更多智能体和更多轮次能提升准确率。

跨模型组合优于单一模型辩论：ChatGPT + Bard 的组合优于任一单独模型。

### 稀疏拓扑

"Improving Multi-Agent Debate with Sparse Communication Topology"（arXiv:2406.11776，2024-2025）表明全连接辩论并非总是最优。稀疏拓扑（星型、环型、辐射型）能以更低的 token 成本匹配准确率。每个辩手只看到部分对等方。

含义：

- 全连接 N=5、R=3 = 5 × 3 = 15 个提议，每个读取 4 个对等方 = 60 次批评操作。
- 星型 N=5、R=3（1 个中心 + 4 个分支）= 15 个提议，分支只读取中心 = 12 次批评操作。

### 辩论何时有帮助

- **事实性。** N 个独立提议，交叉检查减少幻觉。
- **规则遵循。** 国际象棋走法合法性 — 一个模型遗漏规则，其他模型能捕捉。
- **开放式推理。** 多种框架缩小到正确答案。

### 辩论何时有害

- **延迟敏感的用户体验。** N × R 轮串行是你可能无法承受的延迟。
- **成本敏感的规模。** 每个问题 N × R 个 token。
- **简单事实查找。** 一次查找比五次辩论更便宜。

### 2026 年的实际实例

- **Anthropic 编排器-工作者**（第 12 课）— 带综合步骤的辩论变体。
- **LangGraph 主管**（第 13 课）— 中央路由器 + 专家智能体可将辩论实现为一个节点。
- **OpenAI Agents SDK**（第 16 课）— 智能体之间来回交接以进行迭代批评。
- **多智能体评估** — 将辩论与评估器-优化器配对以获取评估信号。

### 这个模式出问题的地方

- **收敛崩塌。** 所有智能体收敛到第一个错误答案。通过要求分歧轮次来缓解。
- **中心故障。** 在星型拓扑中，一个坏的中心会污染所有人。轮换或使用多个中心。
- **提示词同质化。** 所有智能体使用相同提示词；它们产生相同答案。使用多样化提示词和/或模型。

## 开始构建

`code/main.py` 实现了标准库辩论：

- `Debater` 类（脚本化 LLM，每个辩手有观点漂移）。
- `FullMeshDebate` 和 `SparseDebate` 运行器。
- 三个问题：一个事实性、一个规则性、一个推理。
- 指标：收敛答案、收敛轮数、总批评操作数。

运行方式：

```
python3 code/main.py
```

输出：每种协议的准确率和成本；稀疏拓扑在 3 个问题中的 2 个上以更低成本匹配全连接。

- **LangGraph** — 带检查点的有状态多轮辩论。
- **自定义** — 用于研究或专业正确性保证。

## 练习

1. 实现"强制分歧"规则：在第 1 轮，每个辩手必须产生不同的提议。测量对收敛速度的影响。
2. 添加置信度加权聚合：辩手返回（答案、置信度）；聚合器按置信度加权。有帮助吗？
3. 将一个"智能体"替换为具有不同观点的脚本化 LLM。异质性能提升准确率吗？
4. 对你的 3 个问题测量全连接 vs 稀疏的 token 成本。绘制成本 vs 准确率图。
5. 阅读 Society of Minds 论文。将你的演示扩展到 N=5、R=3。什么会出问题？什么会改善？

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|---------|---------|
| 辩论 | "多智能体批评" | N 个提议者、R 轮交叉批评、收敛 |
| 全连接 | "所有人读所有人" | 每个辩手每轮读取所有对等方 |
| 稀疏拓扑 | "有限对等视图" | 辩手只读取部分对等方 |
| 辐射型 | "星型拓扑" | 一个中心辩手，N-1 个分支只读取中心 |
| 收敛 | "达成一致" | 辩手收敛到共享答案 |
| Society of Minds | "Du 等人的辩论论文" | ICML 2024 多智能体辩论方法 |
