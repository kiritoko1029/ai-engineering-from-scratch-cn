# 评估驱动的智能体开发

> Anthropic 的指导："从简单提示词开始，通过全面评估优化它们，仅在需要时添加多步智能体系统。"评估不是最后一步。它是驱动第 14 阶段中所有其他选择的外层循环。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 第 14 阶段全部内容。
**所需时间：** 约60分钟

## 学习目标

- 说出三个评估层 — 静态基准、自定义离线、在线生产 — 及其用途。
- 解释评估器-优化器紧密循环。
- 描述 2026 年最佳实践：评估与代码并行，在 CI 中运行，门控 PR。
- 将第 14 阶段的每节课与其生成的评估用例关联。

## 问题所在

智能体能通过演示。它们在生产中以演示无法预测的方式失败。基准回答的是"这个模型是否广泛有能力？"而非"这个智能体是否在为我的产品推送正确的补丁？"答案是：三个评估层持续运行，每个护栏和学习到的规则都映射到一个评估用例。

## 概念说明

### 三个评估层

1. **静态基准** — SWE-bench Verified 用于代码（第 19 课）、WebArena/OSWorld 用于浏览/桌面（第 20 课）、GAIA 用于通用（第 19 课）、BFCL V4 用于工具使用（第 06 课）。用于跨模型比较和回归门控。污染是真实存在的：SWE-bench+ 发现 32.67% 的解决方案泄露。始终报告 Verified / +-audit 分数。

2. **自定义离线评估** — 你的产品形态：
   - LLM 评委（Langfuse、Phoenix、Opik — 第 24 课）。
   - 基于执行（运行补丁，检查测试）。
   - 基于轨迹（将动作序列与标准对比；OSWorld-Human 显示顶级智能体是标准的 1.4-2.7 倍）。

3. **在线评估** — 生产环境：
   - 会话回放（Langfuse）。
   - 护栏触发的告警（第 16、21 课）。
   - 每步成本/延迟追踪（第 23 课 OTel span）。

### 评估器-优化器（Anthropic）

紧密循环：

1. 提议者生成输出。
2. 评估器评判。
3. 优化直到评估器通过。

这是 Self-Refine（第 05 课）的泛化。任何你关心的智能体流程都可以用评估器-优化器包裹以提高可靠性。

### 2026 年最佳实践

- 评估与代码并行。
- 在 CI 中每个 PR 上运行。
- 以评估分数门控合并（例如"与 main 相比无 > 5% 的回归"）。
- 每个护栏映射到一个评估用例。
- 每个学习到的规则（Reflexion、pro-workflow 学习规则）映射到一个失败用例。

### 评估驱动开发失败的地方

- **没有基线。** 没有最近已知正常状态的评估无法阅读。存储基线。
- **LLM 评委缺乏依据。** 评委也会幻觉。CRITIC 模式（第 05 课）— 评委基于外部工具验证。
- **过度拟合评估。** 为评估优化偏离了生产实用性。轮换用例。
- **不稳定的评估。** 非确定性用例导致误报。固定种子，快照状态。

## 开始构建

`code/main.py` 是一个标准库评估工具：

- 带分类（基准、自定义、在线）的用例注册表。
- 被测的脚本化智能体。
- 评估器-优化器循环：提议、评判、优化直到通过或达到最大轮数。
- CI 门控：聚合通过率 + 与基线的回归对比。

运行方式：

```
python3 code/main.py
```

输出：每用例的通过/失败、回归标志、CI 门控裁定。

## 使用建议

- 将评估用例与智能体代码写在同一仓库中。
- 通过 CI 在每个 PR 上运行。
- 回归时构建失败。
- 跟踪通过率随时间的变化。
- 将每个生产失败关联到一个新用例。

## 交付产物

`outputs/skill-eval-suite.md` 为智能体产品构建一个三层评估套件，包含 CI 门控和回归追踪。

## 练习

1. 取你的一次生产失败。编写一个能复现它的评估用例。你的智能体现在能通过吗？
2. 为你的领域构建一个三维度的 LLM 评委评分标准（事实性、语气、范围）。对 50 个会话打分。
3. 将评估套件接入 CI。>=5% 回归时构建失败。
4. 添加轨迹效率指标：智能体用了多少步 vs 标准轨迹？
5. 将第 14 阶段的每节课映射到你套件中的一个评估用例。有缺失吗？那就是需要弥补的差距。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|---------|---------|
| 静态基准 | "现成评估" | SWE-bench、GAIA、AgentBench、WebArena、OSWorld |
| 自定义离线评估 | "领域评估" | 针对你的产品形态的 LLM 评委/执行/轨迹评估 |
| 在线评估 | "生产评估" | 会话回放、护栏告警、成本/延迟追踪 |
| 评估器-优化器 | "提议-评判-优化" | 迭代直到评委通过 |
| CI 门控 | "合并阻断器" | 评估回归时构建失败 |
| 基线 | "最近已知正常" | 用于检测回归的参考分数 |
| 轨迹效率 | "步数/标准比" | 智能体步数除以人类专家最少步数 |
