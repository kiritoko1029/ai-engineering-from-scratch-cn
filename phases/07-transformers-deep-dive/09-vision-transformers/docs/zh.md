# 视觉变换器（ViT）

> 图像是由像素块构成的网格，句子则是由词元构成的网格。同样的变换器可以处理这两种结构。

**类型：** 构建
**语言：** Python
**先修课程：** 第7阶段 · 05课（完整Transformer模型）、第4阶段 · 03课（卷积神经网络）、第4阶段 · 14课（视觉Transformer简介）
**耗时：** 约45分钟

## 问题所在

在2020年之前，计算机视觉领域主要依赖卷积技术。ImageNet、COCO以及各类检测基准测试中的最先进模型均采用CNN作为核心架构，而Transformer则主要用于处理语言任务。

Dosovitskiy等人于2020年发表的论文《一张图片相当于16×16个单词》表明完全可以摒弃卷积操作。只需将图像切分为固定大小的块，再将每个块线性投影为嵌入向量，最后将这些向量序列输入普通的Transformer编码器即可。在足够的训练规模下（如ImageNet-21k级别的预训练或更大规模），ViT的性能能够与基于ResNet的模型相媲美甚至超越它们。

2026年，ViT开启了一种更为普遍的发展模式：一种架构，多种模态应用。Whisper用于音频的分词处理，ViT则用于图像的分词处理；机器人技术中使用动作令牌，视频处理中使用像素令牌。Transformer并不关心具体输入的类型——只要将其作为序列输入，它就能进行学习。

到2026年，ViT及其衍生架构（如DeiT、Swin、DINOv2、ViT-22B、SAM 3）已主导了大多数视觉处理任务。在边缘设备以及对延迟要求较高的场景中，CNN依然具有优势；而在其他所有领域，其技术栈中几乎都会包含某种形式的ViT架构。

## 概念概述

![图像 → 补丁 → 令牌 → 变换器](../assets/vit.svg)

### 步骤 1 —— 应用补丁

将 `H × W × C` 分量的图像分割为 `N × (P·P·C)` 分量的平面块序列。典型配置为：`224 × 224` 分量的图像，使用 `16 × 16` 分量的块进行分割 → 共生成 196 个块，每个块包含 768 个数值。

```
image (224, 224, 3) → 14 × 14 grid of 16x16x3 patches → 196 vectors of length 768
```

补丁大小是影响性能的关键因素。较小的补丁意味着更多的令牌，更高的分辨率，但注意力计算成本呈二次方增长；较大的补丁则会导致分辨率降低，计算成本也随之减少。

### 步骤 2 — 线性嵌入

一个经过训练的矩阵可将每个扁平块投影到 `d_model` 维度。这等价于核大小为 `P`、步长也为 `P` 的卷积操作。在 PyTorch 中，其实现实际上就是 `nn.Conv2d(C, d_model, kernel_size=P, stride=P)` —— 仅需两行代码即可完成。

### 步骤 3 — 在开头添加 `[CLS]` 标记，并加入位置嵌入

- 在输入序列前添加一个可学习的 `[CLS]` 令牌。该令牌的最终隐藏状态即为用于分类的图像表示。
- 添加可学习的位置嵌入（源自 ViT）或正弦型二维嵌入（后续版本采用）。
- 在 2024 年及以后的版本中，RoPE 被扩展为用于表示位置的二维形式，有时无需显式的位置嵌入。

### 第 4 步 —— 标准 Transformer 编码器

该架构由多组 `LayerNorm → Self-Attention → + → LayerNorm → MLP → +` 的模块堆叠而成，与 BERT 完全相同。其中不包含任何针对视觉任务的专用层。这正是该论文在教学设计上的核心亮点。

### 第 5 步 —— head

对于分类任务：将 `[CLS]` 隐藏状态输入线性层，再通过 softmax 函数进行输出。而对于 DINOv2 或 SAM 模型，则直接使用补丁嵌入，无需考虑 `[CLS]` 状态。

### 重要的变体

| 模型 | 发布年份 | 变更点 |
|-------|----------|--------|
| ViT | 2020 | 最初的版本。固定补丁大小，采用全全局注意力机制。 |
| DeiT | 2021 | 基于蒸馏技术；仅可在 ImageNet-1k 数据集上进行训练。 |
| Swin | 2021 | 采用分层结构与移位窗口设计。成本函数为固定次二次型。 |
| DINOv2 | 2023 | 自监督学习（无需标签）。具备最佳的通用视觉特征提取能力。 |
| ViT-22B | 2023 | 参数量为 220 亿；遵循缩放律特性。 |
| SigLIP | 2023 | 结合 ViT 与语言对，采用 Sigmoid 对比损失函数。 |
| SAM 3 | 2025 | 可对任意对象进行分割；基于 ViT-Large 架构并配有可提示的掩码解码器。 |

### 为何需要这么长时间

ViT 需要大量数据才能与 CNN 相媲美，因为它缺乏 CNN 所具有的归纳偏置（如平移不变性和局部性）。在没有超过 1 亿张带标签的图像或强大的自监督预训练支持的情况下，即便在相同的计算资源下，CNN 依然更具优势。DeiT 在 2021 年通过蒸馏技术解决了这一问题；而 DINOv2 则在 2023 年借助自监督学习彻底解决了该问题。

## 构建它

参见 `code/main.py`。该实现仅使用标准库完成补丁处理、线性嵌入以及合理性检查，无需训练过程——因为任何实际规模的 ViT 模型都需要 PyTorch 并耗费数小时的 GPU 计算时间。

### 步骤 1：生成虚假图像

一个 24 × 24 的 RGB 图像表示为多行 `(R, G, B)` 元组组成的列表。我们采用 6×6 的图像块划分方式，即生成 16 个块，每个块对应一个长度为 108 的嵌入向量。

### 步骤 2：应用补丁

```python
def patchify(image, P):
    H = len(image)
    W = len(image[0])
    patches = []
    for i in range(0, H, P):
        for j in range(0, W, P):
            patch = []
            for di in range(P):
                for dj in range(P):
                    patch.extend(image[i + di][j + dj])
            patches.append(patch)
    return patches
```

栅格顺序：在网格上采用行优先方式。所有 ViT 模型均使用此顺序。

### 步骤 3：线性嵌入

将每个扁平补丁矩阵与一个随机的 `(patch_flat_size, d_model)` 矩阵相乘。在序列开头添加 `[CLS]` 后，验证输出形状是否为 `(N_patches + 1, d_model)`。

### 第 4 步：统计实现真实 ViT 模型所需的参数数量

输出 ViT-Base 的参数数量：12 层，12 个注意力头，特征维度 d=768，patch 大小为 16。与 ResNet-50（约 2500 万参数）相比，ViT-Base 的参数量约为 8600 万；ViT-Large 的参数量约为 3.07 亿；ViT-Huge 的参数量约为 6.32 亿。

## 使用它

```python
from transformers import ViTImageProcessor, ViTModel
import torch
from PIL import Image

processor = ViTImageProcessor.from_pretrained("google/vit-base-patch16-224-in21k")
model = ViTModel.from_pretrained("google/vit-base-patch16-224-in21k")

img = Image.open("cat.jpg")
inputs = processor(img, return_tensors="pt")
out = model(**inputs).last_hidden_state   # (1, 197, 768): [CLS] + 196 patches
cls_emb = out[:, 0]                       # image representation
```

**DINOv2嵌入是2026年图像特征处理的默认选择。** 通过冻结主干网络，仅训练较小的头部网络即可。该架构适用于分类、检索、检测及字幕生成等任务。Meta发布的DINOv2模型检查点在所有非文本视觉任务上的表现均优于CLIP。

**补丁尺寸的选择。** 小型模型采用16×16的补丁尺寸（如ViT-B/16）。用于密集预测（分割）的任务则使用8×8或14×14的补丁尺寸（如SAM、DINOv2）。超大模型通常采用14×14的补丁尺寸。

## 练习题

1. **简单。** 运行 `code/main.py`。验证补丁数量是否等于 `(H/P) * (W/P)`，且平面补丁的尺寸是否为 `P*P*C`。
2. **中等难度。** 实现二维正弦位置嵌入——为每个补块的 `row` 和 `col` 分别生成两个独立的正弦编码，并将它们拼接起来。将这些编码输入到一个小型的 PyTorch ViT 模型中，然后在 CIFAR-10 数据集上比较其与可学习位置嵌入的准确率。
3. **高难度。** 构建一个三层结构的 ViT（使用 PyTorch），在 1,000 张 MNIST 图像上以 4×4 的补块大小进行训练，并测量测试准确率。接着，在相同的 1,000 张图像上加入 DINOv2 预训练步骤（简化版：仅训练编码器，使其能够根据被遮蔽的补块预测出对应的嵌入向量）。准确率会有提升吗？

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| Patch | “视觉变换器的标记” | 图像中 `P × P × C` 区域的像素值构成的扁平向量。 |
| Patchify | “切割并展平” | 将图像分割为互不重叠的块，再将每个块展平为向量。 |
| `[CLS]` 标记 | “图像摘要” | 添加在开头的学习型标记；其最终的嵌入向量即为图像表示。 |
| 归纳偏置 | “模型所假设的内容” | ViT 的先验条件比 CNN 少，需要更多数据来填补这一差距。 |
| DINOv2 | “自监督视觉变换器” | 通过图像增强与动量教师模型在无标签情况下进行训练。2026 年表现最佳的通用图像特征提取模型。 |
| SigLIP | “CLIP 的继任者” | 结合 ViT 与文本编码器，并采用 Sigmoid 对比损失进行训练；在相同计算资源下性能优于 CLIP。 |
| Swin | “带窗口的视觉变换器” | 具有分层结构的 ViT，结合局部注意力机制与移位窗口技术；时间复杂度为次二次级。 |
| 注册标记 | “2023 年的技巧” | 一些额外的学习型标记，用于吸收注意力集中的“低值区域”，从而提升 DINOv2 的特征质量。 |
