# GPT — 因果语言建模

> BERT 能够同时感知信息的正反两面，而 GPT 仅能回溯过去。三角形掩码是现代人工智能领域中影响最为深远的单行代码。

**类型：** 构建
**语言：** Python
**先修知识：** 第7阶段 · 02（自注意力机制）、第7阶段 · 05（完整Transformer模型）、第7阶段 · 06（BERT）
**耗时：** 约75分钟

## 问题所在

语言模型回答一个问题：给定前 `t-1` 个标记，标记 `t` 的概率分布是什么？通过训练该信号——即下一个标记的预测——即可得到能够逐个生成任意文本的模型。

若要端到端地并行训练整个序列，则需要确保每个位置的预测仅依赖于更早的位置。否则模型只需查看答案就能轻易“作弊”。

因果掩码正是为了解决这一问题。它是一个由 `-inf` 值构成的上三角矩阵，在对注意力分数应用 softmax 之前加入该矩阵。经过 softmax 处理后，这些位置的得分将变为 0。这样每个位置只能关注自身及更早的位置。由于只需对整个序列应用一次该掩码，因此在一个前向传播中即可获得 N 个并行的下一个标记预测结果。

GPT-1（2018年）、GPT-2（2019年）、GPT-3（2020年）、GPT-4（2023年）、GPT-5（2024年）、Claude、Llama、Qwen、Mistral、DeepSeek、Kimi——它们都是采用相同核心机制的仅解码器的因果变换器。区别仅在于数据规模更大、质量更高，以及经过更优化的强化学习对齐技术。

## 概念概述

![因果掩码生成三角形注意力矩阵](../assets/causal-attention.svg)

### 掩码

给定一个长度为 `N` 的序列，构建一个 `N × N` 矩阵：

```
M[i, j] = 0       if j <= i
M[i, j] = -inf    if j > i
```

在应用 softmax 函数之前，需先在原始注意力分数上加上 `M`。由于 `exp(-inf) = 0`，被遮蔽的位置将不会产生任何权重贡献。注意力矩阵的每一行都仅表示对先前位置的概率分布。

实现成本：仅需一次 `torch.tril()` 调用。计算耗时：纳秒级。对该领域的影响：深远且全面。

### 并行训练，串行推理

训练过程：将整个 `(N, d_model)` 长度的序列进行一次前向传播，计算 N 个交叉熵损失值（每个位置一个），将其求和后进行反向传播。该操作沿序列方向并行执行。这正是 GPT 训练能够高效扩展的原因——在单次 GPU 运行中即可处理一批包含 100 万个标记的序列。

推理过程：需要逐个生成标记。输入 `[t1, t2, t3]` 可得到 `t4`，输入 `[t1, t2, t3, t4]` 可得到 `t5`，以此类推。KV 缓存（见第 12 课）会保存 `t1…tn` 的隐藏状态，从而避免在每一步都重新计算它们。但推理时的串行处理深度等于输出长度。这就是自回归机制带来的性能代价，也是为何解码会成为所有大型语言模型延迟的瓶颈所在。

### 损失函数——移位一

给定标记序列 `[t1, t2, t3, t4]`：

- 输入：`[t1, t2, t3]`
- 目标值：`[t2, t3, t4]`

对于每个位置 `i`，计算 `-log P(target_i | inputs[:i+1])` 并求和。该值即为整个序列的交叉熵。

所有你了解过的 Transformer 语言模型都是基于此损失函数进行训练的。无论是预训练、微调还是 SFT，使用的都是相同的损失函数，仅数据不同而已。

### 解码策略

训练完成后，采样策略的重要性远超人们的想象。

| 方法 | 功能说明 | 适用场景 |
|--------|----------|----------|
| 贪心采样 | 每一步均选择概率最大的选项 | 需要确定性结果的场景，如代码补全 |
| 温度参数 | 将对数似然值除以温度值后进行采样 | 需要创造力的场景，温度值越高，输出多样性越大 |
| Top-k采样 | 仅从概率最高的k个候选项中选取 | 能有效过滤掉概率极低的选项 |
| Top-p（核采样） | 从累积概率大于等于p的最小候选集中进行采样 | 自2020年起成为默认方案，可自动适应概率分布的形态 |
| Min-p采样 | 仅保留满足`p > min_p * max_p`条件的候选项 | 自2024年起出现，相比Top-p更能有效排除长尾概率项 |
| 推测解码 | 先由小型模型生成N个候选词，再由大型模型进行验证 | 在保持相同质量的前提下可将延迟降低2–3倍 |

到2026年，对于开源权重模型而言，Min-p采样结合温度参数0.7是一个合理的默认配置。而对于任何生产环境下的推理系统来说，推测解码已是不可或缺的技术手段。

### 是什么让“GPT 配方”得以成功？

1. **仅解码器结构。** 无编码器开销，每层仅需一次注意力机制计算加上FFN层。
2. **参数规模扩展。** 从1.24亿参数发展到15亿、175亿，乃至数万亿参数。Chinchilla参数规模扩展定律（第13课）可指导如何合理分配计算资源。
3. **上下文学习能力。** 此功能大约在60亿至130亿参数的模型中出现，使得模型无需微调即可根据少量示例进行学习。
4. **基于人类反馈的强化学习。** 通过训练后的优化，结合人类偏好，将原始预训练文本转化为聊天助手。
5. **预归一化 + RoPE + SwiGLU。** 这些技术组合有助于实现大规模下的稳定训练。

自GPT-2以来，其核心架构并未发生太大变化。所有重要的进展都体现在数据质量、模型规模以及训练后的优化处理上。

## 构建它

### 步骤 1：因果掩码

参见 `code/main.py`。仅有一行代码：

```python
def causal_mask(n):
    return [[0.0 if j <= i else float("-inf") for j in range(n)] for i in range(n)]
```

在应用 softmax 函数之前，将其加入注意力分数中。这就是整个机制的全部内容。

### 步骤 2：一个类似 GPT 的双层模型

堆叠两个解码器模块（掩码自注意力 + FFN，不包含交叉注意力）。添加一个词元嵌入层、位置编码层以及解嵌入层——该解嵌入层与词元嵌入矩阵相连，这是自 GPT-2 以来便采用的常规做法。

### 步骤 3：下一个标记预测，端到端

在包含20个词条的简易词汇表上，为每个位置生成对数概率值。以错位一个位置的真实标签作为基准计算交叉熵损失。由于不涉及梯度计算，此操作仅用于验证前向传播的正确性。

### 步骤 4：采样

实现贪婪采样、温度采样、top-k采样、top-p采样以及min-p采样。使用相同的固定提示语运行这几种方法，并对比其输出结果。该采样函数仅有10行代码。

## 使用它

PyTorch 2026年常用写法：

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3.2-3B-Instruct")
tok = AutoTokenizer.from_pretrained("meta-llama/Llama-3.2-3B-Instruct")

prompt = "Attention is all you need because"
inputs = tok(prompt, return_tensors="pt")
out = model.generate(
    **inputs,
    max_new_tokens=64,
    temperature=0.7,
    top_p=0.9,
    do_sample=True,
)
print(tok.decode(out[0]))
```

在底层实现中，`generate()` 函数会执行前向传播，获取最终位置的逻辑斯蒂值，采样下一个标记并将其追加到结果序列中，随后重复此过程。所有用于生产环境的 LLM 推理框架（vLLM、TensorRT-LLM、llama.cpp、Ollama、MLX）均采用相同的循环结构，并通过批量预填充、连续批处理、KV 缓存分页以及推测性解码等高级优化技术来提升性能。

**GPT 与 BERT 的区别，各一行：** GPT 预测 `P(x_t | x_{<t})`。BERT 预测 `P(x_masked | x_unmasked)`。模型的损失值决定了其是否具备生成能力。

## 练习题

1. **简单。** 运行 `code/main.py`，验证经过 softmax 处理后的因果注意力矩阵是否为下三角矩阵。抽查：第 3 行的权重应仅出现在第 0–3 列。
2. **中等难度。** 实现宽度为 4 的束搜索算法。在 10 个简短的提示语上，比较束搜索（beam-4）与贪婪算法的困惑度。束搜索是否总能取得更好的结果？（提示：通常适用于翻译任务，不适用于开放式对话。）
3. **高难度。** 实现推测性解码：使用一个小型 2 层模型作为初稿，再使用一个 6 层模型进行验证。在完成 100 次长度为 64 的文本生成任务时，测量实际运行速度的提升幅度，并确认最终输出与验证器使用的贪婪算法结果一致。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| 因果掩码 | “三角形” | 添加到注意力分数上的上三角 `-inf` 矩阵，使得位置 `i` 只能看到位置 `≤ i` 的内容。 |
| 下一个标记预测 | “损失函数” | 模型输出分布与每个位置的真实下一个标记之间的交叉熵。 |
| 自回归 | “一次生成一个” | 将输出作为输入再次输入模型；仅在训练阶段存在并行性，生成阶段则没有。 |
| 对数似然值 | “预软归一化分数” | 语言模型头在应用软归一化之前的原始输出；采样即在此数值上进行。 |
| 温度参数 | “创造力调节旋钮” | 将对数似然值除以温度参数 T；T→0 表示贪婪采样，T→∞ 表示均匀采样。 |
| Top-p 抽样 | “核抽样” | 将分布截断为总和至少为 p 的最小集合，然后从剩余部分进行采样。 |
| Min-p 抽样 | “优于 Top-p 的方法” | 保留满足 `p ≥ min_p × max_p` 条件的标记；会根据分布的尖锐程度动态调整截断阈值。 |
| 推测解码 | “草拟 + 验证” | 先用成本较低的模型生成 N 个标记，再由大型模型并行进行验证。 |
| 教师强制法 | “训练技巧” | 在训练过程中，使用真实的上一标记而非模型的预测值作为输入。这是所有序列到序列语言模型的标准做法。 |
